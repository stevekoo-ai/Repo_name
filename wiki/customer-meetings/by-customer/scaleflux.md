## 현재 관계 상태 (최신 미팅 기준)

- **관계**: 파트너 (협업 재정렬 합의, 2026-08-11)
- **단계**: 자사 System 기반 집중 전환, CXL Controller 협업 지속
- **핵심**: **협업 재정렬 3원칙** + **상품기획 조직 관리 이관** (MSR 사고 교훈)

## 핵심 팩트 (누적)
- 자사 **LPDDR 기반 CXL Controller 계획 = 분기 모니터링, 현재 Hold** → 향후 System 기반 집중. ScaleFlux는 LPD 콘셉트 자체 Value 인정.
- System 집중해도 Module 필요 → **CXL Controller 협업 지속**. DRAM+NAND Hybrid Controller는 ScaleFlux 내부 Hold, 필요 시 재개 가능.
- **과거 사고**: MSR이 자사 관여 없이 프로그램 진행→연락 끊김→ScaleFlux 측 프로그램 취소 판단. → 향후 **SK hynix 상품기획 조직이 관리** 요청 받음.
- **협업 재정렬**: ① LPD 개발 중단 ② POR CXL Controller 집중 + **Compression IP 추가** ③ Pooled(Switchless) 협업 지속.

## 후속 액션 / 미해결
- [ ] Pooled(Switchless) 협업 진행 (상품기획 조직 관리 하)
- [ ] Compression IP 추가 반영
