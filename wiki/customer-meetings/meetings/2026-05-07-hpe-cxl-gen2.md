## 상세 정리

### 시장 동향 — 메모리 Shortage가 CXL 도입 가속
- 메모리 Shortage 상황 = 오히려 CXL 메모리 채택 **앞당길 수 있는** 촉매
- 고객 메모리 Reuse 목적 → CXL AIC 채택 문의 지속 접수
- AIC = 초기 고객 CXL **Acceptance 역할** → 이후 다른 Form-factor·use case로 단계적 확장

### Form-factor 진화 전망 (핵심 인사이트)
- **AIC Serviceability**: 현재는 떨어지나, 고객 CXL 채용 후 Training → Serviceability 개선된 FF로 자연 이동 예상
- **장기**: AIC와 E3.S 둘 다 필요하나, **E3.S가 주(main)** 될 전망 (김의현 TL 견해)
- **512GB 확보**: E3.S로는 한계 → E3.L 필요 시 **Back-plane Longer** 고려
- **DDR6**: 지금부터 논의 필요 (타이밍 중요)

### HPE 측 제안 / 입장
- AIC에 controller 탑재 → DIMM socket 또는 Solder down 방식 → **1TB급** 용량 확장 유연성 확보 inform
- Serviceability 측면 고려 시 → **E3.S가 더 확장**될 것으로 전망

### Gen2 CXL 컨트롤러 / 샘플 일정
- **Gen2 CXL 컨트롤러 = Third party Montage** 재확인 (경쟁사 중국 CXMT 계열)
- 개발 상태: X8 backplane 대기 (next couple of months) → 이후 X4 backplane에서 자사 sample test
- **Launch 목표: 내년 6월 (2027-06)**, Venice platform (SP7 / SP8 both)
- 자사 2월 sample → acceptable

### 유럽 규정 — PQC (Post-Quantum Cryptography)
- Dec'27 규정 변경 → 유럽 제공 위해 **자사 PQC FU 필수**
- 자사 status 확인 후 HPE에 inform 필요
