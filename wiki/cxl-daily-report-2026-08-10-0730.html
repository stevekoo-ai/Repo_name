용어 주석 (처음 등장하는 줄임말·기술 용어 풀이)

CXL(Compute Express Link): CPU와 메모리를 고속으로 연결하는 산업 표준 규격. 여러 서버가 메모리를 나눠 씀. · HBM(High Bandwidth Memory): 고대역폭 메모리, AI 연산용. · HBM4: HBM 4세대, NVIDIA "Vera Rubin"에 탑재. · DRAM: PC·서버 주기억장치. NAND: 비휘발성 플래시. · FMS(Flash Memory Summit): 플래시/메모리 산업 행사. · ISCA(International Symposium on Computer Architecture): 컴퓨터 아키텍처 학회. · CapEx(Capital Expenditure): 설비투자. YoY: 전년 동기 대비. TCO: 총소유비용. · KV cache: AI 추론 시 이전 결과를 임시 저장·재사용하는 메모리. · 메모리 풀링: 여러 서버가 하나의 메모리 자원을 나눠 씀. 메모리 확장(expansion): 한 서버에 메모리를 직접 추가. · LTA(Long-Term Agreement): 장기공급계약. MR-MUF: SK Hynix HBM 선진 패키징. · Vistara: Meta 자체 설계 CXL 2.0 메모리 확장용 커스텀 칩. · TC-NDEF: Samsung HBM 고밀도 적층 공정. CXMT: 중국 메모리사 창샹메모리. · CoWoS/FOPLP/CoPoS: TSMC 선진 패키징 기술.

1. HBM 점유율 구도가 "SK Hynix 압도적 우위"에서 "Samsung 추격 + SK Hynix 리스크"로 재편

Samsung HBM4 수율이 2월 양산 시작 시 <60%에서 80%로 급상승(TC-NDEF + 1c DRAM 베이스 출하 80% 초과), 2026 종료 전 HBM 점유율 ~38% 목표로 NVIDIA Vera Rubin 공급 가속. 반대로 SK Hynix는 2026 5차 단체교섭이 이익공유구조(전년 영업이익 10% 보너스, 80% 즉시+20% 2년, treasury shares lock-up)를 둘러싸 교착되어 출하 차질 리스크 부상. TrendForce는 Samsung 점유율 급증·SK Hynix 잠정 트리밍 예상. 1호 기준선 "SK 62/Micron 21/Samsung 17"은 범위·방향성 재정정 필요. CXL 시사점: HBM4 공급 원활화 → GPU/AI 가속기 확대 → CXL 풀의 호스트 기반 확대. 단, SK Hynix 노사 분쟁은 HBM 단기 공급 리스크. 출처 (단일 출처 — TrendForce 단독 보도)

2. Meta의 CXL 실배포 정량 메트릭 획득 — "CXL 메모리 = DDR5의 13%"은 강력한 TCO 신호이나 조건부

Meta가 ISCA 2026에서 자체 설계 Vistara ASIC(두 개 72-bit DDR4 채널을 CXL 2.0 Gen5로 브리지)로 CXL 메모리를 실배포. 256GB CXL + 768GB DDR5 = 1TB/노드(AMD Turin), 플릿 43.7%가 RAM 부족으로 정체 해소가 목적. 비용 "13센트/달러"는 강력하나 "이미 건물에 있고 이미 지불한 폐기 DDR4 재활용"이라는 조건이 붙어 신규 CXL 카드 비용과는 다름. 성능 DDR5 614GB/s@130ns vs CXL 76GB/s@250ns(8:1 대역폭, ~60% 지연 패널티) — CXL은 대역폭이 아닌 용량 목적임이 정량 확인. 핵심: "스위치/패브릭 기반 풀링은 여전히 largely a demo" — CXL 2.0 직접 확장(expansion)은 실배포, CXL 3.x 다자간 풀링은 데모 단계. 상품기획은 확장 먼저, 풀링 후속 단계 분리로 접근. 출처 (2차 보도 — 근거 Meta ISCA 2026 paper)

3. DRAM/NAND 가격 상승폭이 기준선 상향 — "저비용 NAND 오프로드" 가정에 압력

Adata는 Q3 DRAM +20~30%, NAND +35~40% 예상(NAND가 DRAM 상승폭 상회). 1호 기준선 "Q3 DRAM +13~18%" 상향이자, DRAFT 2.4절(CXL 하이브리드 DRAM+NAND)의 "NAND 저비용 계층" 가정에 직접 영향 — NAND 단가 상승이 진행 중이면 CXL 하이브리드에서 NAND의 비용 우위 약화. Winbond는 고객이 2029/2030년까지 LTAs 요청, "2027년이 2026년보다 메모리 더 타이트" 전망. CXMT 증설로도 공급 부족 상쇄 불가, 2027년 H1까지 가격 상승 지속. 출처

4. "CXL 없는 rack-scale AI 시스템"과 "CXL over optics 랙 간 풀링"은 같은 AI rack의 두 얼굴

AMD Helios는 72 가속기·31TB HBM4·2.9 EFLOPS의 rack-scale 시스템을 CXL 없이 GPU 패브릭(scale-up 260TB/s, scale-out 43TB/s)으로 구성 — DRAFT 6장 "CXL vs GPU 패브릭은 다른 레이어" 결론 실증. 반면 Kyocera/Pegatron/SMART CXL-over-optics 데모(Computex 2025)는 CXL/PCIe 링크를 광으로 전송해 고밀도 AI 랙에서 저밀도 랙으로 메모리 오프로드. 즉, AI 랙의 고밀도화(Helios·VR NVL72, 150kW 냉각)가 진행될수록, 그 열/전력/공간 제약을 완화하기 위해 CXL 원격 메모리 풀링(광 링크 경유)의 가치가 올라간다 — 두 경로는 경쟁이 아닌 보완 레이어. 출처 · 출처

5. 풀링(pooling) vs 확장(expansion)의 단계 분리가 상품기획의 핵심

Meta 실배포 정량이 명시한 "스위치 기반 풀링은 여전히 데모"는, CXL 상품기획이 (1) CXL 2.0 직접 확장(실배포, Meta Vistara식 DDR4 재활용 또는 신규 CXL 카드) → (2) CXL 3.x 다자간 풀링(스위치 필요, 데모→실배포 전환 중)의 2단계 로드맵으로 접근해야 함을 시사. 즉각 상품화 후보는 확장(단일 호스트 용량 병목 해소), 풀링은 다자간 활용도·composability 확립 후속. 출처

목적: delta는 기준선 대비 수치/사실 변경을 잡는 도구일 뿐. 최종 목표는 부품 나열이 아닌 "이번에 등장한 부품/카드/기술/SW가 어떤 full-stack 시스템 솔루션을 구성하는가, 그것이 AI + Pooled Memory + Rack-in/out 아키텍처를 어떻게 바꾸는가"를 도출하는 것.

시나리오 1: CXL over optics → 랙 간 원격 메모리 풀링 실증 (Computex 2025, 맥락 실증 사례)

⚠️ 2025-07-06 과거 기사(Computex 2025). 2026-08-10 사용자 피드백이 "이런 full-stack 사례를 놓쳤다"고 지적한 회취용 실증 사례. delta가 아닌 full-stack 시나리오 실증 사례로 사용(날짜 규칙 준수).

L1 미디어L2 컨트롤러L3 링크/물리L4 스위치L5 랙L7 시스템
L1 미디어: SMART CXL memory card(opposed DIMM mounting)
L2 컨트롤러: SMART CXL 카드 통합 컨트롤러
L3 링크/물리: Kyocera PCIe-to-optical 변환 카드 + MTP/MPO multimode cable + near-packaged optical engine. x16 연결(광엔진 추가, Kioxia FMS 2024 x4 대비 고속화)
L4 스위치/패브릭: CXL 3 switch(향후 배포 참조, 본 데모엔 미포함)
L5 랙/물리: Pegatron server — 고밀도 샤시에서 저밀도 랙으로 메모리 오프로드
L7 시스템: AI 클러스터의 메모리/가속기를 저밀도 랙으로 오프로드 → 고밀도 AI 랙 공간/전력/열 제약 완화

동작 방식: 전기 CXL/PCIe 신호를 Kyocera 카드에서 광으로 변환 → multimode fiber(MTP/MPO 4본)로 원격 전송 → Pegatron 서버가 원격 CXL 메모리 카드에 접근. CXL/PCIe 링크를 광으로 "running" — 물리적 분리 가능한 메모리 풀 구성.

AI Rack 관점: AI 클러스터가 메모리/가속기를 저밀도 랙으로 오프로드 → 고밀도 AI 랙(Helios·VR NVL72, 150kW 냉각)의 공간/전력/열 제약 완화. Rack-in/out에서 메모리를 물리적으로 분리된 랙에 두는 disaggregation 실증.

시스템 의미/시사점: CXL이 단일 랙 내 기술에서 랙 간 fabric 기술로 확장되는 실증. 광물리(L3)가 CXL 메모리 풀링(L1+L4)의 물리적 범위 결정 — InP 부족(3호 delta-7)이 이 확장의 상류 제약. DRAFT 2장 + 8장 연결. 단, 본 데모는 풀링 SW(L6)와 CXL 3 switch(L4) 미포함 → "풀링은 여전히 데모"(Meta ISCA 2026)와 정합.

시나리오 2: Meta Vistara ASIC → CXL 2.0 직접 확장 실배포 (확장 vs 풀링 단계 분리)

L1 미디어L2 컨트롤러L3 링크L5 랙L6 오케스트레이션L7 시스템
L1 미디어: 폐기 DDR4 DIMM(32GB ×4 = 128GB/칩, 듀얼 256GB) — 이미 지불된 자본 재활용
L2 컨트롤러: Meta 커스텀 Vistara ASIC(두 72-bit DDR4 채널을 CXL 2.0 Gen5로 브리지)
L3 링크/물리: CXL 2.0 over PCIe Gen5(광 아닌 전기 직접 연결)
L4 스위치/패브릭: 없음 — 직접 확장(expansion)은 스위치 불필요. 풀링(스위치 필요)은 "largely a demo"
L5 랙/물리: 표준 서버 랙(AMD Turin 158-core/316-thread 노드)
L6 오케스트레이션: Linux kernel tiering(numa_demotion_enabled=1, numa_balancing=2, zone_reclaim_mode=7), 마이그레이션 오버헤드 <0.5%
L7 시스템: Meta 플릿 43.7% RAM 부족 정체 → 용량 병목 해소. DRAM이 서버 탄소배출 69% → 용량 효율로 탄소 절감

동작 방식: Vistara ASIC이 DDR4 채널을 CXL 2.0로 브리지 → 호스트 CPU가 CXL 메모리를 second-tier capacity로 인식 → Linux tiering이 hot/cold 페이지를 DDR5/CXL 간 자동 마이그레이션. 스위치 없이 단일 호스트에 직접 연결(expansion).

AI Rack 관점: 본 배포는 AI 추론/KV cache 아닌 일반 워크로드 용량 확장. CXL이 대역폭(76GB/s)이 아닌 용량(256GB 추가) 목적임이 정량 확인 — KV cache 오프로드(대역폭 민감)에는 한계, 용량 병목(43.7% 정체) 해소에 강점.

시스템 의미/시사점: 확장(expansion) vs 풀링(pooling) 단계 분리가 핵심. (1) CXL 2.0 직접 확장 = 실배포(Meta, 스위치 불필요, 용량 목적). (2) CXL 3.x 다자간 풀링 = 데모(스위치 필요, composability 목적). 상품기획은 확장 먼저, 풀링 후속 로드맵. "13% 비용"은 폐기 DDR4 전제 조건부. DRAFT 8장 + 9장 + 11.2절 연결.
