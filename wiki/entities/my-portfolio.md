DC(퇴직연금), IRP, ISA, 일반 4개 계좌로 구성된 개인 투자 포트폴리오. 스냅샷을
`/ingest` 할 때마다 이 페이지를 최신 상태로 갱신한다.

**🔧 자동 수집 파이프라인 (2026-07-25 신설, 같은 날 GEN→ISA→IRP 순으로 완성)**:
4개 계좌 전부 한국투자증권(KIS) 소속 확인 —
[`scripts/portfolio_holdings.py`](../../scripts/portfolio_holdings.py)가
KIS API로 계좌별 보유종목·평가금액·손익을 매일 19:10 KST에 자동 조회해
`sources/portfolio-holdings.csv`에 기록한다([`.github/workflows/portfolio-holdings-sync.yml`](../../.github/workflows/portfolio-holdings-sync.yml)).
계좌번호는 GitHub Secrets(`KIS_ACCOUNT_GEN`/`KIS_ACCOUNT_ISP`/`KIS_ACCOUNT_DC`/`KIS_ACCOUNT_IRP`)에만
저장. **🔴 핵심 발견 — KIS 앱키는 계좌번호 하나에 묶여서 발급된다**(KIS
Developers 신청현황 화면에 계좌별로 별도 행이 뜨는 게 증거): GEN 계좌용
앱키(`KIS_APP_KEY`) 하나로 ISA·IRP까지 조회하려던 게 "output1 없음"
실패의 진짜 원인이었다. 계좌별 전용 앱키(`KIS_APP_KEY_ISP`/`KIS_APP_SECRET_ISP`,
`KIS_APP_KEY_IRP`/`KIS_APP_SECRET_IRP`)를 사용자가 KIS Developers에서
추가 발급받아 등록하면서 **ISA·IRP도 같은 날 저녁 전부 해결** — GEN·ISA·IRP
3개 계좌가 이제 매일 자동 수집된다. **DC만 여전히 미해결**이나, 이건
API 문제가 아니라 KIS 공식 문서에 "55번 계좌(DC가입자계좌)는 해당 API
이용이 불가합니다"라고 명시된 **구조적 미지원**이라 코드로 해결 불가능한
영역. 아침·저녁 Routine이 이 CSV를 읽어 "계좌별 보유종목의 거시환경 대비
유불리 판단 + 전망 + 체크포인트" 표를 리포트에 포함한다(사용자 요청) —
이 판단 자체는 GitHub Actions가 아니라 Routine 세션(Claude)이 매번 직접
수행, CSV가 없으면 섹션 자체를 생략한다.

(7/28 19:10 KST 예정 동기화가 아직 미도착 — 확인된 지연). 즉 아래 표는
**CXMT 쇼크(7/28, SK하이닉스 -14.65%) 반영 전** 금액이다. 참고로 SK하이닉스

## 리스크: SK하이닉스 집중

포트폴리오의 가장 큰 특징은 [SK하이닉스](sk-hynix.md) 단일 종목 집중이다.
(아래는 2026-07-13 스냅샷 기준 — **최신 수치는 위 "최신 스냅샷" 섹션
참고**: 2026-07-25 기준 GEN+ISA 138주, 242,742,000원, 3개 계좌 합산
대비 약 75.8%)

- ISA 19주 + 일반 117주 = 136주, 평가금액 합계 296,760,000원
- **전체 포트폴리오(454,407,129원)의 약 65%**를 이 한 종목이 차지
- 전체 손익(+278,164,072원)의 약 89%(+247,678,000원)가 이 한 종목에서 발생
  (일반 계좌분 매입원가 29,685,000원 → 평가 255,060,000원, +759.22%)
- 반도체 익스포저는 ISA(삼성전자·ACE미국반도체TOP3+·SOL AI반도체소부장),
  IRP(KIWOOM 삼성전자&SK하이닉스채권혼합)에도 분산되어 있지만, 사실상
  SK하이닉스 한 종목의 등락이 전체 수익률을 좌우하는 구조 — 2026-07-13
  본주 -16.15% 급락([차트 실측](../summaries/sk-hynix-adr-krw-chart-comparison-2026-07-13.md))이
  포트폴리오 평가금액에도 직접 영향을 준다.

전체 33개 보유 종목의 상세 수치는
[계좌 현황 스냅샷 (2026-07-13)](../summaries/portfolio-holdings-2026-07-13.md) 참고.

**업데이트(2026-07-15)**: SK하이닉스가 7/13 -16.15% 급락 이후 7/15
+10.93%~+12.02%까지 [급등](../summaries/sk-hynix-adr-surge-breakout-2026-07-15.md)하며
136주 평가금액도 그만큼 크게 되돌아왔을 것으로 추정된다 (정확한 갱신 금액은
새 계좌 스냅샷을 넣어야 확정 가능 — 아직 반영 전). 이번처럼 유리한 방향으로
크게 흔들렸다는 사실 자체가, 집중도가 높은 포트폴리오는 등락 폭도 그만큼
크다는 걸 보여주는 사례다.

**업데이트(2026-07-22)**: 7/13 급락(-16.15%) 이후 등락을 거쳐 7/20
최저 종가(1,764,000원)까지 재차 눌렸다가, 7/21(+4.08%)·7/22 장중(+8~9%,
200만원 돌파 시도)로 연속 급반등 — 136주(ISA 19 + 일반 117) 기준 평가금액이
**약 2.7~2.8억원 수준**으로 확인돼 기존 296,760,000원 추정치와 대체로
부합한다. 상세는 [SK하이닉스](sk-hynix.md)의 "7/22 급등 배경" 섹션 참고.

[사용자](user-profile.md)는 SK하이닉스 재직자이자 고소득의 상당 부분이
PS(성과급)에서 나오는 구조라, 위 SK하이닉스 집중 리스크는 투자자산에 그치지
않고 소득 측면과도 겹친다 — 회사 실적이 흔들리면 자산과 소득이 동시에 영향을
받는 구조.
