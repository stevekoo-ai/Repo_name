## 🆕 개별 매물 실측 — 수지진산마을푸르지오 (2026-10-28, 네이버페이 부동산)

사용자가 **본인 거주 단지**(수지진산마을푸르지오, 풍덕천동)의 네이버페이
부동산 매물 스크린샷 6장을 직접 제공. 원문:
[sources/suji-jinsan-prugio-naverpay-listings-2026-10-28.md](../../sources/suji-jinsan-prugio-naverpay-listings-2026-10-28.md).

**주의**: 아래는 위 섹션의 MOLIT 법정동(41465) 단위 실거래/신고가 통계와
다른 종류의 데이터다 — **특정 단지의 현재 호가(매물) 스냅샷**(거래
완료가 아닌 매도/임대 희망가)이며, 집계 평균이 아니라 단일 단지
표본이라 법정동 평균과 직접 비교해 해석하지 않는다.

**매매 (전용 84㎡형, 5건 중 4건)**: 10.13 14억(104동) → 10.23 13.8억
(101동, "플랫폼시티인접" 표기) → 10.28 14.3억(101동) — 2주 안에
호가가 올랐다 내렸다 하는 좁은 밴드(13.8~14.3억)에서 움직였고, 뚜렷한
단방향 추세는 아니다. 143㎡형(105동, 15.3억)은 더 넓은 평형이라
직접 비교 대상이 아니다.

**전세 (112A/113B형, 3건)**: 7.5억~7.6억으로 매물 간 거의 차이가 없다
— 매매 14억대 대비 전세가율 약 53~54%.

**월세 (3건, 전환 패턴)**: 보증금이 낮을수록 월세가 크게 뛴다 —
1억/260만원, 2억/210만원, 4억/140만원. 보증금 1억 올릴 때마다 월세가
약 30~40만원씩 줄어드는 흐름으로, 전세 7.5억을 기준점으로 보면 보증금
3억 차이에 월세 120만원 차이 → 암묵적 전월세전환율 **연 약 4.8%**
(120만×12 ÷ 3억 — 2026-10-29 정정: 이전 "14~16%대"는 계산 오류, 아래 손익분기 4.58~4.80%와 같은 값).

**이 데이터가 왜 중요한가**: 이 단지는 사용자가 **지금 실제로 사는
단지**이고 전세 만료(2027-02-22, 갱신불가)가 걸려 있다. 지금 전세
시세(7.5~7.6억)가 재계약 시 기준선이 될 가능성이 높고, 매매가(14억대)
대비 전세가율 53~54%는 "전세 대신 매매 전환"의 비용 격차를 보여준다 —
[주거 전환 자금 조달 실행 프레임워크](../concepts/housing-funding-execution-framework.md)의
목표 조달액(128,652,000원)이 전세 재계약을 가정한 수치라면, 이 단지
실측 전세가(7.5억대)와 대조해 재계산 여지가 있는지 확인할 필요가 있다.

**호가 vs 모델 시세 (2026-10-29 추가)**: 리치고 산출 시세(10/29 기준, 모델 추정이지 실거래 아님) — 34평 매매 12.59억·**전세 6.78억**, 43평 전세 7.45억. 34평 매매 매물 7건(13억~14.3억). 10/28 전세 호가 7.5~7.6억은 모델 시세보다 **약 10~12% 높다** → 협상 여지 또는 시세 반영 지연 둘 다 가능(판단 불가, 실거래 확인 필요). 출처: https://m.richgo.ai/realty/danji/a8ZWwzb

**실시간 매물 수집 가능 여부 (2026-10-29 시험)**: 네이버 부동산은 이 클라우드 환경에서 접속 불가(시간 초과). 직방 API는 단지 정보·매매 시세는 응답하나 아파트 전월세 매물 목록은 0건(진산푸르지오 id 23242 등 3개 단지 시험). 국토부 전월세 실거래 API 키는 GitHub Secrets에만 있고 현 수집기(`collectors/molit_rent.py`)는 수지구 평균만 저장 — 단지별 거래 행은 없음. → 단지별 매물은 사용자 스크린샷이 유일한 경로.

### 기회비용 반영 시 순위 — 전세 vs 월세, 어느 쪽이 더 싼가

단순 명목가 비교는 틀린 질문이다 — 전세는 보증금을 통째로 묶어두고
월세는 그중 일부만 묶어둔다. 묶인 돈의 기회비용(차액 보증금을 다른
곳에 굴렸을 때 벌 수 있는 수익)을 더해야 "실질 월 비용"으로 공정하게
비교된다. 사용자 지적대로 **발행어음(종금사, 한국투자증권·미래에셋
등) 수익률이 5%대로 가능**해 기준금리(3.0%, 2026-09)보다 훨씬
현실적인 기회비용이다.

**손익분기 전환율**(전세 7.5억 기준, 이 전환율보다 기회비용이 높으면
그 월세가 전세보다 싸짐):

| 월세 매물 | 손익분기 전환율 |
|---|---:|
| 101동 2억/210만원 | 4.58% |
| 104동 1억/260만원 | 4.80% |
| 106동 4억/140만원 | 4.80% |

**r=5%(발행어음 기준) 적용 시 실질 월 비용**:

| 매물 | 실질 월 비용 |
|---|---:|
| **101동 2억/210만원 (월세)** | **293.3만원 — 최저** |
| 104동 1억/260만원 (월세) | 301.7만원 |
| 106동 4억/140만원 (월세) | 306.7만원 |
| 101동/102동 7.5억 (전세) | 312.5만원 |
| 102동 7.6억 (전세) | 316.7만원 |

**판정**: 기준금리(3.0%)로 계산하면 전세가 가장 싸지만, 발행어음
수익률(5%)을 기회비용으로 쓰면 **월세 3건 모두가 전세보다 싸지고**,
그중 **101동 2억/210만원이 전체 최저**다 — 세 손익분기 전환율
(4.58~4.80%) 모두 5%보다 낮기 때문. 즉 이 판단은 "보증금 차액을 실제로
5%대에 굴릴 수 있는가"에 전적으로 좌우된다. 굴릴 수 있다면 월세가
유리, 그럴 수단·의향이 없다면 전세가 유리 — 숫자 자체보다 **보증금
차액의 실제 운용 가능성**이 핵심 변수.
