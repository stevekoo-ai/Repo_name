---

# Creation Rules

Create an Entity only if:

- monitored continuously
- referenced repeatedly
- maintains evolving state
- affects decisions

---

# Update Rules

Prefer updating an existing Entity over creating a new one.

Avoid duplicates.

Maintain continuity.

---

# Core Principle

Every important report should improve understanding of at least one Entity.
