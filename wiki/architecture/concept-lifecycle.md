# Concept Lifecycle

Observation
    ↓
Candidate Concept
    ↓
Active Concept
    ↓
Mature Concept
    ↓
Merge / Archive

---

# Creation Rules

Create a Concept only if:

- reusable
- explains multiple events
- changes future decisions
- captures important lessons

Otherwise use a Summary.

---

# Expansion Rules

Expand existing Concepts before creating new Concepts.

---

# Merge Rules

Merge overlapping Concepts.

Prefer one strong Concept over several weak Concepts.

---

# Archive Rules

Archive Concepts that are:

- obsolete
- invalidated
- no longer useful

Concepts are reusable intelligence.
