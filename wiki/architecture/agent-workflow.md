# Agent Workflow

## Standard Workflow

Collect
    ↓
Summarize
    ↓
Update Entity
    ↓
Apply Concepts
    ↓
Analyze State
    ↓
Assess Impact
    ↓
Generate Report
    ↓
Record Learning

---

# Rule

A workflow that generates reports but leaves no reusable learning is incomplete.

The Wiki should become more intelligent after every cycle.
