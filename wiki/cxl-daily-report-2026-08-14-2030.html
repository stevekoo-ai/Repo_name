📊 Delta 상세 — 기준선(DRAFT v0.7 + 6호) 대비 변경

★★★ Delta-1 Microsoft Azure CXL attached memory private preview

🟢 사실층: Microsoft Azure M-series VM에 Astera Labs Leo CXL Smart Memory Controllers 통합. 타겟: AI inference, LLM KV cache, in-memory DB. "첫 주요 CSP CXL attached memory 배포" — private preview 단계.

🔴 해석층: CSP(hyperscaler)가 CXL attached memory를 실제 서비스에 투입 — "CXL이 클라우드에서 진짜 쓰이는가"에 "예"라는 첫 답변. DRAFT 11.2절 CSP 동향과 12.2(옵션 4: CSP composable infra)에 핵심 반영.

📝 DRAFT 반영: 기존: "Meta: DDR4 대체 보고." → → 변경: "🆕 Microsoft Azure M-series에 Astera Labs Leo CXL Smart Memory Controllers private preview — 첫 주요 CSP CXL 메모리 배포."

★★★ Delta-2 NVIDIA Vera CPU, CXL 3.1 + PCIe 6.4 — Intel/AMD 제압

🟢 사실층: NVIDIA Vera CPU — 88 Olympus cores, CXL 3.1 + PCIe 6.4 지원. "Among the first chips to support CXL 3.1 and PCIe 6.4, beating out Intel, and possibly AMD." 50% faster agentic sandbox, 1.2 TB/s memory throughput.

🔴 해석층: NVIDIA가 GPU(Vera Rubin)뿐만 아니라 CPU까지 CXL 3.1 구현 → CXL 생태에서 NVIDIA 영향력 GPU → CPU까지 확대. CXL 상품기획: "NVLink + CXL 하이브리드 아키텍처" 가능성 → 진영 중립적 메모리 풀 가치 재확인.

📝 DRAFT 반영: 기존: (5.1b에 Vera 없음) → → 변경: "NVIDIA Vera — CXL 3.1 + PCIe 6.4, 88 Olympus cores, Intel/AMD 제압. Rubin GPU와 AI pair."

★★★ Delta-3 DRAM 웨이퍼 크라우딩 — HBM 23% 흡수, DDR5 비용 2배

🟢 사실층: HBM 생산이 전 세계 DRAM 웨이퍼의 ~23% 흡수 → DDR5 ECC RDIMM 비용 2배(doubled). Q3 40-50% 추가 상승, Q4 30% 추가 전망.

🔴 해석층: CXL 풀링 가치 proposition 한층 강화(HBM 비싸고 부족 → CXL DDR5 기반 저비용). 단, DDR5 가격 2배 상승은 CXL 모듈 원가에도 직접 반영 — 양면성.

📝 DRAFT 반영: 기존: "AI 서버 수요로 DRAM 상승 사이클 지속" → → 변경: "🆕 HBM 생산이 DRAM 웨이퍼 23% 흡수 → DDR5 ECC RDIMM 비용 2배. CXL 풀링은 HBM 대비 저비용 경로이나, 원가도 DDR5 가격 영향 받음."

★★ Delta-4 SK Hynix 214% YoY 매출, DRAM 점유율 Samsung 39% 역전

🟢 사실층: SK Hynix 214% YoY 매출 급등 but DRAM 점유율 26% → Samsung 39% 역전. Samsung HBM에서 "growing traction" 확보.

🔴 해석층: SK Hynix 매출 성장은 HBM/AI DRAM에서, 표준 DRAM 점유율은 Samsung 주도. CXL CMM-D용 DDR5 원물 공급에서 Samsung 규모 우위 지속 가능성.

📝 DRAFT 반영: 기존: "SK Hynix 1c DRAM node aggressive ramp vs Samsung HBM4 yield recovery." → → 변경: "Samsung DRAM 점유율 39% vs SK Hynix 26% 역전. SK 214% YoY 매출 급등 but 표준 DRAM 점유율 Samsung 주도."

★★ Delta-5 Vistara ASIC — millions of servers 생산, AI inference 서버 25% 절감

🟢 사실층: Vistara ASIC (Microsoft 커스텀): Legacy DDR4 → DDR5 서버 브리지. "Production across millions of servers". AI inference 서버 수 25% 절감. kernel drivers 공개 중.

🔴 해석층: CXL 풀링이 데모→생산 단계 진입. "millions of servers production" = CXL 컴포저블 인프라의 현실화. DRAFT 4장(Vistara ASIC 신규 엔트리) + 11.2절(CSP 동향).

📝 DRAFT 반영: 기존: "Liqid: CXL 풀링 어플라이언스" → → 변경: "🆕 Vistara ASIC: Legacy DDR4 → DDR5 브리지, 'millions of servers production', AI inference 서버 25% 절감."

★★ Delta-6 DRAM 가격 Q3 40-50% 추가 상승, TrendForce "둔화 시작"

🟢 사실층: TrendForce(Aug 12): "Pricing gains persist but slowing". 소비자 DRAM budget limit로 가격 상승 둔화 시작. Q3 40-50% 추가 상승, Q4 30% 추가.

🔴 해석층: AI 서버 DRAM은 여전히 상승, 소비자 DRAM은 가격 탄력성 한계 도달. CXL 풀링 채택에 양면성: AI DRAM 가격 상승 = CXL 가치 강화, 하지만 CXL 모듈 원가(DDR5)도 상승.

📝 DRAFT 반영: 기존: "DRAM 가격 이중 추세(소비자 둔화 + AI/서버 지속)" → → 변경: "🆕 TrendForce(Aug 12): 가격 상승 지속 but 둔화 시작. Consumer DRAM undersupplied but budget limit 도달."

★ Delta-7 Hot Chips 2026 — XCENA CXL-based memory expansion 플랫폼 데모

🟢 사실층: Hot Chips 2026 (8/23-25, Palo Alto, CA — 6호 Seattle 오타 정정). XCENA CXL-based memory expansion platform with near-data processing 데모 예정.
