# 환율 국면과 달러 자산

사용자 질문(2026-09-10) — "환율이 떨어지면(원화 강세) 달러를 살 거고, 그 달러를
그냥 두기보다 주식·채권에 투자할 거다. 그럼 **5번의 환율 국면에서 나스닥·S&P·
금리·채권은 어떻게 움직였나**, 그리고 지금은 어떤 달러 투자처를 봐야 하나."

[36개월선 하회 국면 전수분석](usdkrw-below-ma36-episodes.md)이 "언제 원화가
강했나"를 정리했다면, 이 페이지는 **"그때 달러로 뭘 샀어야 했나"** 에 답한다.

> **데이터**: `sources/macro-series.csv`. 2026-09-10에 미국 주식·금리 계열을
> 2005년까지 백필해서 처음으로 계산이 가능해졌다(그 전엔 미국 주식 계열이
> 저장소에 하나도 없었고 `us_10y`도 2016년부터였다).
> **채권 수익률은 합성치**다 — ICE BofA 총수익지수를 FRED가 라이선스 때문에
> 최근 3년만 공개해서, `engine/fx/bond_return.py`가 DGS10/DGS2 금리에서
> 상수만기 파채권을 매월 재평가하는 방식으로 총수익을 만든다(평평한
> 수익률곡선 가정 — 롤다운 수익 미반영, 그래서 "근사").

## 0. ⚠️ 먼저 — 이 분석이 뒤집은 직관 3가지

이 페이지에서 하나만 가져간다면 이것이다.

1. **국면 전체를 보유하면 환차익이 거의 0이다.** 국면의 시작과 끝은 둘 다
   "MA36 교차점"이라 **양끝의 환율 레벨이 비슷하다**. ①국면 20개월을 통째로
   들고 있어도 환율 손익은 −0.9%였다. 환차익은 국면 보유가 아니라
   **국면 안의 저점에 환전해서 국면이 끝난 뒤에 회수**할 때 나온다.
2. **환율 국면은 "환전 타이밍"에만 정보를 주고 "투자처 선택"엔 거의 정보를
   주지 않는다.** MA36 하회 중 진입 vs 아무 때나 진입을 비교하면 환율 자체는
   +3.4~3.5%p 유리한데(12·24개월), 나스닥 초과성과는 12개월 기준 **+0.0%p**다.
   나스닥이 이긴 건 국면 특성이 아니라 **시대 특성**(2011~2024 미국 강세장)이다.
3. **딱 하나, 국면과 자산이 진짜로 연결되는 지점이 있다 — 장기채다.**
   국면 종료 트리거는 6번 중 5번이 미국 긴축 전환이었고, 긴축 전환 = 금리
   상승 = **장기채 평가손**이다. 국면 종료 직후 진입한 10년물의 12개월 수익
   중앙값은 **−0.3%**로, 아무 때나 진입한 경우(+3.9%)보다 **4.2%p 열위**다.

## 1. 국면 中 보유 — 환차익은 없고, 주식만 벌었다

각 국면의 시작월→종료월. 달러 기준 수익률.

| 국면 | 기간 | 환율 | 나스닥 | S&P(대용) | 10년물 | 2년물 | 달러현금 |
|---|---|---:|---:|---:|---:|---:|---:|
| ① | 2010-09~2012-04 | −0.9% | **+28.6%** | +12.6% | +9.5% | +0.9% | +0.1% |
| ② | 2012-06~2013-04 | −3.5% | +13.4% | **+20.3%** | +1.1% | +0.4% | +0.1% |
| ③ | 2013-08~2014-10 | −3.3% | **+29.0%** | +10.3% | +7.0% | +0.3% | +0.0% |
| ④ | 2017-10~2018-09 | −0.5% | **+19.6%** | +5.7% | −3.3% | −0.2% | +1.6% |
| ⑤ | 2020-10~2021-07 | +1.6% | **+34.5%** | +27.4% | −2.4% | +0.0% | +0.0% |

**환율 열을 보라 — 20개월짜리 ①조차 −0.9%다.** MA36 교차로 국면을 정의하는
한 양끝 환율이 비슷할 수밖에 없는 구조적 결과지, 원화가 안 움직였다는 뜻이
아니다(①의 국면 내 최저점은 MA 대비 −11.9%였다).

**달러현금이 사실상 0%인 게 이 시대의 특징이다** — ①②③⑤ 전부 미국이 제로금리
근처였다. "달러를 그냥 들고 있으면 손해"라는 통념은 이 시기엔 문자 그대로
사실이었다. **지금은 3개월물이 3.94%다(2026-09-08)** — 뒤의 §5에서 다시 다룬다.

## 2. 저점에 환전했다면 — 5/5 전부 통했다

각 국면에서 환율이 가장 낮았던 달에 원화→달러 환전, 이후 회수까지 포함한
**원화 환산** 수익률(자산수익 × 환율변화 왕복).

| 국면 | 저점 | 환율 | | 12개월 | 24개월 | 36개월 |
|---|---|---:|---|---:|---:|---:|
| ① | 2011-07 | 1,054원 | 환율만 | +7.2% | +6.5% | −2.5% |
| | | | 나스닥 | +14.4% | +40.1% | +54.6% |
| | | | 10년물 | +22.7% | +12.5% | +5.9% |
| ② | 2012-12 | 1,063원 | 환율만 | −0.8% | +2.6% | +10.0% |
| | | | 나스닥 | +37.3% | +60.9% | +82.4% |
| | | | 10년물 | **−9.2%** | +3.8% | +12.5% |
| ③ | 2014-06 | 1,012원 | 환율만 | +10.5% | +14.1% | +13.1% |
| | | | 나스닥 | +25.0% | +25.3% | +57.5% |
| | | | 10년물 | +14.6% | +30.4% | +22.4% |
| ④ | 2018-03 | 1,061원 | 환율만 | +7.1% | +14.9% | +6.2% |
| | | | 나스닥 | +17.2% | +25.2% | +99.2% |
| | | | 10년물 | +13.3% | +44.5% | +22.2% |
| ⑤ | 2020-12 | 1,086원 | 환율만 | +9.4% | +16.0% | +18.9% |
| | | | 나스닥 | +32.8% | **−5.8%** | +38.4% |
| | | | 10년물 | +5.0% | **−6.9%** | −1.0% |

- **환율만 놓고 봐도 24개월 기준 5/5 전부 플러스**(+2.6~+16.0%). 저점 환전은
  통했다.
- **나스닥은 36개월 기준 5/5 전부 +38% 이상**, 최대 ④의 +99.2%.
- **채권의 두 번의 사고**가 정확히 §0-3의 메커니즘이다: ②의 −9.2%는 2013년
  테이퍼 탠트럼, ⑤의 −6.9%는 2022년 연준 급속 긴축.

> ⚠️ **이 표는 실전 전략이 아니다.** "저점"은 사후에만 알 수 있다(look-ahead
> bias). 표본도 5개뿐이다. 이 표가 말해주는 건 "저점을 맞히면 얼마를 벌었다"가
> 아니라 **"국면 안 어디쯤에서 환전해도 방향은 맞았다"** 는 것이다 — 그 검정이
> 바로 다음 §3.

## 3. 🔬 그래서, 국면 판단이 실제로 값어치가 있나 — 검정

2005~2026 전 구간에서 MA36 하회 여부를 매월 기계 판정(261개월 중 **84개월,
32%가 하회**)하고, "하회 중 진입" vs "아무 때나 진입"의 원화 환산 수익률
중앙값을 비교했다.

| 진입 후 | 자산 | 무조건 진입 | MA36 하회 중 | **차이** | 하회 중 플러스 비율 |
|---|---|---:|---:|---:|---:|
| 12개월 | 환율만 | +0.4% | +3.8% | **+3.4%p** | 66% |
| | 나스닥 | +15.4% | +15.4% | **+0.0%p** | 91% |
| | S&P | +7.4% | +8.8% | +1.4%p | 85% |
| | 10년물 | +3.5% | +5.8% | +2.4%p | 72% |
| 24개월 | 환율만 | +2.8% | +6.3% | **+3.5%p** | 72% |
| | 나스닥 | +28.9% | +32.8% | +3.9%p | 98% |
| | S&P | +16.3% | +14.2% | **−2.2%p** | 93% |
| | 10년물 | +7.5% | +14.4% | +6.9%p | 73% |
| 36개월 | 환율만 | +5.0% | +4.7% | **−0.3%p** | 72% |
| | 나스닥 | +49.9% | +55.4% | +5.5%p | 100% |
| | 10년물 | +14.4% | +12.5% | −1.9%p | 89% |

**결론 — 국면 정보의 값어치는 짧고, 환율에만 붙는다.**

- **환율**: 12·24개월에서 +3.4~3.5%p로 일관되게 유리. 36개월엔 사라진다(−0.3%p).
  국면 정보는 **1~2년짜리 환전 판단**에만 쓸 수 있다는 뜻이다.
- **주식**: 12개월 +0.0%p. **국면은 주식 선택에 아무 정보도 주지 않는다.**
  하회 중 진입의 나스닥 플러스 비율이 91~100%인 건 국면이 좋아서가 아니라
  이 표본기간에 나스닥이 거의 항상 올랐기 때문이다.
- **채권 24개월 +6.9%p**는 유일하게 커 보이지만 **아래 한계 때문에 신뢰하지
  않는다**.

> ⚠️ **통계적 한계(반드시 같이 읽을 것)**: ①표본이 겹친다 — 12개월 창을 매월
> 굴리면 인접 표본이 11/12를 공유하므로 유효 표본 수는 249가 아니라 사실상
> 국면 수(5~7)에 가깝다. 유의성 주장은 불가능하다. ②표본기간(2005~2026)이
> **미국 주식 장기 강세장 + 2022년까지 채권 강세장**이다. ③국면 저점 표본은
> 5개다. **그래서 이 표는 "국면 판단으로 초과수익을 낸다"의 근거가 아니라,
> "국면 판단으로 자산선택까지 하려 들면 안 된다"의 근거로 쓴다.**

## 4. 국면 종료 경고가 진짜로 쓸모 있는 곳 — 장기채

§3에서 국면→자산 연결이 거의 다 끊어졌는데, **딱 하나 살아남는 게 있다.**

국면 종료(MA36 재돌파) 달에 진입했다면, 달러 기준:

| 국면 | 종료 | 10년물 12M | 10년물 24M | 나스닥 12M | 그 사이 10Y 금리 변화 |
|---|---|---:|---:|---:|---:|
| ① | 2012-05 | −3.4% | −3.7% | +22.2% | +0.57%p |
| ② | 2013-05 | −0.3% | +5.2% | +22.8% | +0.32%p |
| ③ | 2014-11 | +1.7% | +2.0% | +6.6% | +0.03%p |
| ④ | 2018-10 | **+16.2%** | +26.4% | +13.5% | **−1.46%p** |
| ⑤ | 2021-08 | **−13.5%** | −17.1% | −22.6% | **+1.85%p** |
| | **중앙값** | **−0.3%** | +2.0% | +13.5% | |
| | *무조건 진입* | *+3.9%* | | | |

**국면 종료 직후 12개월 장기채 = 중앙값 −0.3%, 무조건 진입 대비 −4.2%p.**
5개 중 3개가 마이너스다. 인과가 분명하다 — 국면을 끝내는 게 미국 긴축 전환
이고, 긴축 전환이 곧 금리 상승이며, 금리 상승이 곧 장기채 평가손이다.

**유일한 예외 ④(+16.2%)가 오히려 규칙을 증명한다**: 2018-10 국면 종료는
긴축이 아니라 **미중 무역전쟁+반도체 하강**이 원인이었고, 실제로 그 뒤
연준이 완화로 돌아서며 금리가 −1.46%p 내렸다. **"종료 트리거가 무엇이냐"를
구분하면 장기채 판단이 갈린다** — [FRS 설계](../architecture/fx-regime-score-design.md)의
종료 트리거 감지기가 답해야 할 질문이 바로 이것이다.

## 5. 현 시점(⑥ 진행 중) — 과거 5개 국면과 결정적으로 다른 점

2026-09-08 실측:

| 항목 | 현재 | 과거 5개 국면 대비 |
|---|---:|---|
| 원/달러(ECOS 고시) | 1,342.6원 | MA36 대비 하회 진행 중(2개월째) |
| **미국 3개월물** | **3.94%** | **①②③⑤는 0% 근처, ④만 1.6% — 사상 최고** |
| 2년물 | 4.39% | |
| 10년물 | 4.80% | |
| 10Y−2Y | +0.41%p | 정상화(역전 해소) |
| VIX | 15.7 | 낮음 = 위험선호 양호 |
| 하이일드 스프레드 | 2.67%p | 역사적 저점권 = **위험 보상이 얇다** |
| 달러지수(광의) | 118.1 | |

**가장 중요한 차이는 달러 현금 금리다.** 과거 5개 국면 중 4개는 미국이 제로
금리라 "환전한 달러를 그냥 들고 있기"가 문자 그대로 무수익이었고, 그래서
**주식이든 채권이든 뭐라도 사야 했다**. 지금은 아무것도 안 해도 3.94%다
(§1 표의 달러현금 열 +0.0~+1.6%와 비교하라). **"일단 환전해두고 투자처는
천천히 고른다"가 역사상 처음으로 비용이 거의 없는 선택지가 됐다.**

동시에 **하이일드 스프레드 2.67%p는 역사적 저점권**이다 — 위험을 져도 받는
보상이 얇다는 뜻이라, 크레딧으로 수익을 늘리는 경로는 지금 대가가 나쁘다.

## 6. 판독 규칙 요약

1. 환율 국면 정보는 **환전 타이밍(1~2년)에만** 쓴다. 자산 선택엔 쓰지 않는다(§3).
2. 국면 전체 보유의 환차익은 구조적으로 0에 가깝다 — **저점 환전 후 국면
   종료를 지나 회수**해야 환차익이 생긴다(§1).
3. **국면 종료 경고 = 장기채 경계 신호.** 단, 종료 트리거가 "미국 긴축"인지
   "미국 외 충격"인지를 구분해야 한다 — ④는 후자였고 장기채가 최고 성적을
   냈다(§4).
4. 백테스트 수치는 **겹치는 창 + 5개 국면 표본**이다. 방향의 근거로만 쓰고,
   초과수익의 근거로 쓰지 않는다.
5. 달러 현금 금리를 항상 기준선으로 병기한다 — 0%였던 과거와 3.94%인 현재는
   같은 판단이 나올 수 없다(§5).

## 7. ⚠️ 작업 중 발견 — FRED 레지스트리가 저장소에 두 벌 있다

이 분석을 위해 `scripts/macro_data.py` PRESETS에 금리 계열을 추가하고 2005년까지
백필한 뒤에야, **같은 데이터가 이미 저장소에 더 길게 들어와 있었다**는 걸 알았다.

| 경로 | 저장 위치 | 읽는 쪽 | 실측 범위(예) |
|---|---|---|---|
| `scripts/macro_data.py` PRESETS | `sources/macro-series.csv` | 리포트 엔진·이 분석 | us_10y 2016~ (백필 전) |
| `collectors/fred.py` SERIES | `data/normalized/fred_*.csv` | `engine/macro`, `engine/crisis_analysis`, `engine/rate_analysis` | us_10y_treasury **1962~**, us_2y_treasury **1976~** |

`DGS2`·`DGS3MO`·`DTWEXBGS`·`BAMLH0A0HYM2`는 **양쪽에 중복 등록**돼 있고, 이름만
다르다(`us_2y` vs `us_2y_treasury`). `scripts/build_api_catalog.py`가 만드는
[API 데이터 카탈로그](api-data-catalog.md)는 `collectors/` 쪽만 읽기 때문에
**`macro-series.csv` 계열은 카탈로그에 아예 안 나온다** — 그래서 "이미 있는지"를
카탈로그에서 확인할 방법이 없었고, 그게 이번 중복의 직접 원인이다.

**교차검증 소득**: 하이일드 스프레드가 양쪽 모두 2023년치부터만 있다
(`fred_hy_oas.csv` 2023-07~, 이번 백필 2023-09~). 서로 다른 두 수집 경로가
같은 한계를 보이므로 **수집 실패가 아니라 FRED의 라이선스 제한**이 확실하다.

**이번 분석에 미친 영향**: 없다(2005년치면 5개 국면을 다 덮는다). 다만 이번에
새로 확보한 것은 **주식 3종(`us_nasdaq`·`us_sp500_oecd`·`us_vix`)뿐**이고 —
이건 양쪽 어디에도 없었다 — 금리 4종은 사실상 중복 수집이었다.

> **미결(별도 판단 필요)**: 두 레지스트리를 통합할지, `build_api_catalog.py`가
> `macro_data.py` PRESETS도 읽게 할지. 후자가 훨씬 싸고 재발 방지 효과는
> 같으므로 그쪽을 권한다. 이번 세션 범위 밖이라 손대지 않았다.
