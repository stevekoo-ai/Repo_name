## 왜 이 축이 생겼나

사용자 요청(2026-09-18): "엔캐리 트레이드 청산이 작년에 큰 주식하락을
경험했어. 그래서 이것이 실제적인 문제가 되는가를 트레이스하고 싶어."

**2024-08-05 실제 사례**: BOJ가 2024-07-31에 정책금리를 0.25%로 인상하고
동시에 미국 고용지표가 예상보다 약하게 나오면서, 엔화가 급격히 강세로
돌아섰다(USD/JPY 161→142대). 그동안 낮은 엔화 금리로 자금을 빌려 미국
주식 등 고수익 자산에 투자해온 "엔캐리 포지션"이 동시다발적으로
청산되면서 **닛케이가 하루 만에 -12.4%(1987년 이후 최대 낙폭)**,
S&P500도 같은 주 약 -3% 급락했다. 반도체·AI 주식도 예외 없이 휩쓸렸다.

**이 축이 묻는 것은 "다시 터지느냐 안 터지느냐"가 아니다.** 사용자가
명시적으로 이렇게 규정했다: "엔캐리가 터진다/안 터진다 식으로 단정하지
않고, 현재 숫자가 어느 방향의 위험을 말해주는지를 보는 것." — 이건
[ai-capex-slowdown.md](ai-capex-slowdown.md)의 "서사인가 숫자인가" 질문과
같은 계열이다. 서사(BOJ가 금리를 올렸다)가 아니라 **포지션 데이터**로
판정한다.

## 판독 프레임 — 3개 지표만 본다

사용자가 복잡한 20개 지표 대신 3개로 좁혀서 제시했다. 그대로 채택한다.

| # | 지표 | 왜 이거 하나로 충분한가 |
|---|---|---|
| ① | **CFTC JPY Leveraged Funds Net** | 헤지펀드·레버리지 투자자의 실제 엔화 포지션 — "말"이 아니라 "돈"을 잰다 |
| ② | **USD/JPY 현물** | 포지션 청산이 실제 가격에 반영되는지 확인 — ①이 줄어드는데 ②가 안 오르면 아직 "청산이 일방향으로 진행 중"이 아니다 |
| ③ | **일본 10년물 국채금리** | 일본의 자금조달 비용 + 본국 자금 회귀(repatriation) 압력의 대용치 |

### 왜 CFTC 하나만으로는 판정을 못 내리는가

CFTC 포지션이 줄어드는 것과 엔화가 실제로 강세로 가는 것은 **같이
가야 "청산이 진행형"이라는 뜻**이다. 포지션만 줄고 가격이 안 움직이면
- 청산이 일단락되고 새 캐리가 다시 들어오는 중일 수도 있고
- 아직 남은 Short가 많아서 엔화 강세가 힘을 못 받는 중일 수도 있다

이 둘을 구분하는 게 ②(USD/JPY)의 역할이다.

## 두 시나리오 — 방향으로만 판정한다

### 시나리오 A — 캐리 재개 (위험 낮아지는 방향)

```
CFTC Net:   -49,000 → -70,000 → -100,000  (다시 Short 쌓임)
USD/JPY:       157  →   158   →    160    (엔화 약세 지속)
```
→ 엔캐리가 다시 살아난다. 글로벌 위험자산엔 상대적으로 우호적.

### 시나리오 B — 진짜 위험 신호 (위험 커지는 방향)

```
CFTC Net:   -49,000 → -20,000 →   0    → +30,000  (Short 계속 청산→Long 전환)
USD/JPY:       157  →   154   →  152   →   150     (엔화 강세 지속)
```
→ **포지션 청산과 엔화 강세가 동시에, 지속적으로** 진행 중이라는 뜻.
이때는 캐리 축소 → 글로벌 레버리지 축소로 이어질 가능성을 주의 깊게
본다. 특히 **USD/JPY가 150 아래로 내려가면서 CFTC가 계속 Long 쪽으로
가면** 중요한 경고 신호로 취급한다.

**단정 금지**: 2026-09-18 현재 숫자는 A도 B도 아니다 — CFTC는 크게
청산됐는데(Short -103,023계약 변화, 2월 이후 첫 순매수 전환) USD/JPY는
오히려 157대로 다시 상승했다. 이건 "1차 경고는 발생했지만 2차 대규모
청산이 시작됐다고 볼 단계는 아니다"로 읽는다 — 자세한 실측치는
monitoring 페이지 참고.

## SK하이닉스/반도체와의 연결 — 사용자가 직접 제시한 핵심 트리거

사용자: "나는 엔캐리 자체보다 '엔화 강세 + 미국 장기금리 상승 + 나스닥
하락'이 동시에 나타나는지를 훨씬 중요하게 볼 거야. 그 세 개가 같이
움직이면 이야기가 꽤 달라져."

즉 이 축을 단독으로 보지 않는다. **3중 동시발생 조건**:

| 조건 | 이 저장소의 기존 추적 지점 |
|---|---|
| 엔화 강세 | usd_jpy(FRED, 일일 자동 수집 중) |
| 미국 장기금리 상승 | us_10y(FRED, 일일 자동 수집 중, macro-series.csv) |
| 나스닥 하락 | us_nasdaq(FRED, 일일 자동 수집 중) |

세 개 다 이미 이 저장소가 매일 수집하는 지표라 **새 수집기 없이도
동시발생 여부는 매일 판정 가능**하다 — CFTC 포지션 데이터만 새로
필요하다(아래 "데이터 출처" 참고).

## 데이터 출처와 자동화 현황

| 지표 | 출처 | 수집 상태 |
|---|---|---|
| CFTC JPY Leveraged Funds | CFTC 매주 금요일 발표(Commitment of Traders, Disaggregated) | **미자동화** — 이번 항목은 사용자가 직접 제공한 수치([사용자 제공], 2026-09-08 기준 CFTC 공식 발표분) |
| USD/JPY | FRED `DEXJPUS` | ✅ 자동 수집 중(`usd_jpy`) |
| 일본 10년물 국채금리 | 미확정 — FRED 무료 티어엔 일본 국채 일별 수익률이 없음(월간 OECD 대용만 있음) | **미자동화**, 소스 조사 필요 |
| 나스닥·미10년물(동시발생 판정용) | FRED | ✅ 자동 수집 중 |

⚠️ **CFTC·일본 10년물은 아직 이 저장소가 직접 검증한 실측 데이터가
아니다** — 사용자가 대화에서 제공한 수치를 [사용자 제공]으로 표시해
monitoring 페이지에 기록했다. R1(실측 우선) 원칙상, 자동 수집기가
붙기 전까지는 이 축의 판정에 **사용자가 매주 갱신해주는 CFTC 수치가
필요**하다.

**다음 단계(제안, 승인 대기)**: CFTC는 무인증 공개 데이터(Socrata Open
Data API, `publicreporting.cftc.gov`)를 제공한다 — 오늘 DXY 작업과
같은 방식으로 GitHub Actions에서 먼저 접근 가능 여부를 실측하고,
가능하면 주간 수집기를 `scripts/macro_data.py`에 추가할 수 있다
(발표 주기가 매주 금요일이라 `macro-data-sync.yml`의 일일 스케줄에
얹어도 무방 — 새 데이터 없는 날은 그냥 upsert 0건).
