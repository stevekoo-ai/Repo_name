## 핵심 가설

> **"이번 반도체 반등이 과거 엔비디아 급등 시작과 같은가?"**

성공한 엔비디아 급등의 **3가지 조건(거래량·가격·고점)** 특징을 정의하고, 현재 SK하이닉스가 그 조건을 얼마나 충족하는지를 정량적으로 검증한다.

**데이터 소싱(하이브리드 v3):** KIS API의 해외주식 기간별시세는 가격 데이터만 제공하므로, 거래량은 웹서치+차트 실측(3건)과 공개자료 추정(5건)을 병합한다. vol_source 필드로 데이터 출처를 명시적으로 추적.

## 분석 방법론 (v3 하이브리드)

### 메트릭 정의 (3가지 조건)

1. **거래량배수** (vol_ratio)
   - 기준: 2.0배 이상 = 기관/외국인 수급 신호 강함
   - 범위: 엔비디아 성공 사례 평균 2.09배 (범위 1.5~2.4배)
   - 데이터: 웹서치+차트 실측(3건), 공개자료 추정(5건) 혼합
   - vol_source 필드로 출처 구분: `websearch_chart_measured` vs `chart_estimate`

2. **종가위치** (price_position_pct)
   - 계산: (현재가 - 52주 최저) ÷ (52주 최고 - 52주 최저) × 100%
   - 기준: 80% 이상 = 고가근처 (추진력 있는 상승)
   - 의미: 고점 근처에서 시작하는 강한 모멘텀 신호

3. **10일내고점돌파** (broke_high_10d)
   - 정의: 분석 시점 이후 10거래일 중 이전 52주 고점을 돌파
   - 기준: 달성 = 단기 추세 상향 전환 신호
   - 엔비디아 성공 사례: 88% 달성 (7/8)

### 성공의 정의

엔비디아의 경우 **3가지 조건을 모두 충족**한 사례가 1년 이상 지속 상승으로 이어졌다:

- 거래량 ≥ 2.0배 (기관 신호 강함)
- 종가위치 ≥ 80% (모멘텀 좋음)
- 10일내 고점돌파 ✓ (추세 상향)

**성공 통계**: 8개 사례 중 3가지 모두 충족한 경우 4건 (50%), 이들은 모두 1년 이상 지속 상승

**v3 하이브리드의 혁신**:
- KIS API의 제약을 극복하기 위해 **웹서치+차트 실측**(3건) + **공개자료 추정**(5건) 결합
- vol_source 필드로 각 사례의 데이터 출처를 명시적으로 추적
- 엔비디아 8개 사례 중 3개는 정밀하게 측정된 실제 거래량 데이터로 기준선 설정

**v3-corrected의 수정 사항 (2026-08-01 저녁 발견)**:
- SK하이닉스 `current_price`/`week_52_high`/`week_52_low`가 실제 KIS API 확정 종가(1,718,000원대)와 56배 다른 플레이스홀더 숫자(31,100원대)를 쓰고 있었음을 뒤늦게 발견
- `sources/sk-hynix-price-snapshot.csv` 실측치로 교체, 종가위치 84.8% "✓ 충족" 판정을 무효화
- 52주 최저가는 KIS API 미제공 + 웹서치 값(245,000원)은 최초 재사용 금지 이력 있음 → 이 시점엔 "미검증"으로 하향, 신뢰도 65점→35점(잠정)

**v3-final의 수정 사항 (2026-08-01 밤, 사용자 지적으로 두 단계 재수정)**:
- **증거 재평가**: 245,000원을 기각한 근거("우리 관측과 명백히 불일치")가 사실 설명 없는 메모였고, 반박 이론("23Q1 가격 재활용설")도 계산해보니 32% 오차로 뒷받침이 약함을 사용자가 지적 — 반대로 245,000원은 독립된 두 웹검색에서 재확인된 값이었음. 증거의 무게가 채택 쪽으로 기울어 재검토
- **최종 확정**: 사용자가 실제 증권사 시세창(52주 범위 244,000~3,002,000원)과 TradingView 일봉 차트(52주전 시점 2025-08-01 종가 257,500원, 52주고점 2026-06-23 3,002,000원)를 직접 제공 — 웹서치 추정치와 거의 일치, 차트에 급격한 가격 단절(액면분할 흔적)도 없어 잔여 불확실성 해소
- **결과**: price_position_pct = **53.44%(CONFIRMED)** — 기존 "종가위치 충족(84.8%)"이라는 결론이 실제로는 "종가위치 미충족(53.44%)"으로 정반대였음이 확인됨. 신뢰도 35점→25점(최종)
- **교훈 1**: 새로운 분석 스크립트를 짤 때 참조 가격은 반드시 `sources/*.csv`(KIS API 실측)와 대조 검증할 것 — 임의로 입력한 예시/플레이스홀더 숫자가 그대로 최종 리포트에 남을 위험
- **교훈 2**: "과거에 재사용 금지 처리된 값"이라는 이력 자체를 무비판적으로 신뢰하지 말 것 — 그 이력의 근거가 빈약하면(설명 없는 메모) 재검증 여지를 열어둬야 함. 오늘의 경우 최초 기각 판단이 틀렸을 가능성이 높음
