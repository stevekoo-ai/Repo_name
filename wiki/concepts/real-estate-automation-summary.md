## Part 2: 경기판단(경기지수) 필요 데이터 — 완전성 분석

### 현재 활용 가능한 데이터 (4개 항목)

#### ✅ 1. 부동산 거래가격 추이 (자동화)
- 출처: MOLIT(`real-estate-sync.yml`)
- 빈도: 매일(월간 집계)
- 강점: 공식 통계, 지역·가격대별 세분화
- 약점: **거래 규모/심리는 미포함** (가격은 있지만 "얼마나 많이 거래되는가"는 없음)

#### ✅ 2. 금리 환경 (자동화)
- 출처: ECOS/FRED (`macro-data-sync.yml`)
- 빈도: 월 1회 정기공시
- 강점: 정확도 높음
- 약점: 현물 변화는 선행하지만 거래심리 반영 지연

#### ✅ 3. 신용 유동성 (부분 자동화)
- 출처: KIS API (`sk-hynix-daily-report.yml`에서 신용잔고 호출, 부동산 전용은 아님)
- 빈도: 일일
- 강점: 실시간 신용 조여짐 신호
- 약점: 주식 신용이지 부동산 신용(주택담보대출)은 아님

#### ✅ 4. 국제 요인 (매크로)
- 출처: 미국 지표(FRED)
- 빈도: 월 1회
- 약점: 한국 특화 부동산 정책 미포함

## Part 3: 우선순위별 개발 로드맵

### 🔴 Phase 1 (Immediate — 2주 내) — 자동화 필수 3개

1. **A1: KB국민은행 부동산심리지수**
   - 웹스크래핑 또는 KB API 문의 필요
   - 매월 1회 발표(공개 URL: kb.co.kr/news)
   - 임팩트: 심리 팩터 추가로 "과열/보합/냉각" 판정 정확도 +30%p

2. **B1: MOLIT 신규공급(착공)**
   - MOLIT API 상품 확인 필요(data.go.kr)
   - 빈도: 월 1회(통계청 경유)
   - 임팩트: 3~6개월 가격 상한선 설정 가능

3. **C2: 한은 금통위 의사록**
   - data.go.kr ECOS 또는 한은 공식 웹서치
   - 빈도: 월 1회 (정기 공시)
   - 임팩트: "금리 인상/인하 가능성" 구체화

### 🟡 Phase 2 (High Priority — 1개월) — 자동화 가능 4개

- **A2-A3:** 계약율, 전세가율 (MOLIT 기존 데이터 + 계산)
- **B5:** 인구이동 (통계청 API)
- **E1:** 외국인 거래 (MOLIT API 상품 추가)

### 🟢 Phase 3 (Medium Priority) — 수동 모니터링 4개

- **D1-D3:** 규제·대출·세제 정책 (LLM 웹서치 + 뉴스 모니터링)
- **E2-E3:** 임차인원지수, 전세사기 현황
