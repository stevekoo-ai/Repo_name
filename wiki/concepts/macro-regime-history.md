"지금 미국 거시국면이 어디에 있고, 가장 닮은 과거 스토리가 어떻게
흘러갔는지, 오늘 그 스토리에 가까워졌는지 멀어졌는지"를 매일 추적하는
프레임. 사용자가 다른 대화에서 이미 구축한 방법론(G/I/L 산식, 1954~2026
원자료, 역사적 사례 매칭)을 이 위키의 SK하이닉스 데일리 리포트에 접목한
것 — [HBM Cycle Score](hbm-cycle-score.md)가 "SK하이닉스 미시 축"이라면
이 페이지는 그 위에 얹히는 "거시 배경 축"이다.

## 1. G/I/L 국면 점수

```
G(성장) = -(실업률_t − 실업률_t-12)        # 양수 = 개선
I(물가) = CPI YoY_t − CPI YoY_t-6           # 양수 = 물가 가속
L(유동성) = 연방기금금리_t − CPI YoY_t×100   # 양수 = 긴축적
```

4분면: G>0·I<0 = **recovery** / G>0·I≥0 = **overheat** / G≤0·I>0 =
**stagflation** / 그 외 = **reflation**

**역사적 유사 시기**는 1954~2026년 전체 월별 G/I/L을 z-score로
표준화한 뒤, 오늘과 유클리드 거리가 가장 가까운 과거 달들을 찾는
방식(최근 24개월은 자기상관 방지를 위해 후보에서 제외, 매칭된 시기끼리는
최소 12개월 간격 유지).

## 1-1. 거시지표 자동 수집 도구 (2026-07-24 밤 추가, 같은 날 밤 GitHub Actions로 전환)

[`scripts/macro_data.py`](../../scripts/macro_data.py) — 이 페이지의 G/I/L
계산과는 별개로, 사용자가 대화 중 "금리 지금 어때?", "GDP 어때?" 하고 물으면
바로 답할 수 있게 지표 원자료를 계속 최신으로 쌓아두는 도구. 미국은
FRED(연방기금금리·CPI·실업률·GDP, 표준 series_id라 검증됨), 한국은
ECOS(기준금리·환율, 문서 기억 기반 프리셋이라 `--raw`로 재검증 권장)를 지원.

**아키텍처(투자자수급 트래커와 동일 패턴)**: 처음엔 "Claude가 라이브
대화 중 직접 API를 호출"하는 방식을 생각했지만, 그러려면 이 Claude 환경에도
API 키를 별도로 넣어야 해서(GitHub Secrets는 Actions 러너에만 보임) 사용자가
"GitHub에서 다 수집해두자"로 방향을 바꿨다. 지금 구조:
[`.github/workflows/macro-data-sync.yml`](../../.github/workflows/macro-data-sync.yml)이
매일 07:10 KST에 `python3 scripts/macro_data.py sync`를 실행해 프리셋 전체를
조회하고 `sources/macro-series.csv`(series/date/value/provider/fetched_at
롱포맷)에 upsert·커밋 — **API 키는 GitHub Secrets에만 있으면 되고, Claude는
이 CSV 파일을 읽기만 하면 된다.** investor_flow.py+sk-hynix-daily-report.yml과
완전히 같은 "GitHub이 수집, Claude는 판단/조회"역할 분담.

## 2. 데이터 파이프라인 (아키텍처)

```
sources/macro-database-1954-2026.md   ← 원자료(CPI/실업률/연방기금금리, 사용자 시드데이터)
        │
        ▼
scripts/regime_engine.py              ← G/I/L 계산 + 역사적 매칭 (파이썬, 라우틴이 bash로 직접 실행)
        │
        ▼
이 페이지("체크 이력")에 매일 결과 기록
```

**신규 월 데이터 반영 경로 — 웹검색과 API 두 가지 다 지원**:
- (A) 매일 아침 체크가 `python3 scripts/regime_engine.py`를 실행해 시드
  데이터의 최신월 기준 결과를 계산. 이 최신월이 실제 이번 달보다 오래됐으면
  (CPI/실업률/연방기금금리는 월 1회만 발표되므로), 웹검색으로 신규 발표치를
  확인해 `python3 scripts/regime_engine.py --append-month YYYY-MM --cpi X --unrate Y --fedfunds Z`로
  원자료에 새 행을 추가한 뒤 재계산.
- (B) 사용자가 **이미 다른 Claude Code 세션에서 FRED API 연동 파이프라인을
  운영 중** — 그쪽에서 더 정확한/실시간 수치가 나오면, 그 값을 그대로
  같은 `--append-month` 커맨드에 넣거나 sources/macro-database-1954-2026.md의
  CSV 블록에 직접 append하면 된다. 스크립트 입장에서는 값이 웹검색에서
  왔는지 API에서 왔는지 구분하지 않음 — **어느 경로로 넣어도 동일하게
  작동하도록 설계**. 값을 넣을 때 log.md에 출처(웹검색 vs API)를 남길 것.

**같은 "1950년대 후반 + 2000년대 중반" 군집이 반복 등장한다는 방향성은
일치**하지만, 정확한 월 단위까지는 재현되지 않았음을 투명하게 밝혀둔다.
다음 체크에서 사용자가 원한다면 매칭 로직(exclusion window, z-score
기준기간)을 대화로 맞춰볼 수 있음.

**✅ 해소 (2026-07-26)**: 2026-06 데이터를 append하고 재실행하니 상위
애널로그가 **1957-01·1968-01·2005-11**로 바뀌었다 — 사용자가 다른

2026-05 시드로 계산하고 있었던 기준월 차이**였을 가능성이 크다. 위
"불일치" 기록은 이로써 대부분 설명됨.

## 4. 스토리 프로필 & 관전 포인트 (상위 3개 애널로그)

**2026-07-24 갱신 — 공통점/차이점 + 양방향 시나리오 구조로 고도화**:
사용자 피드백 반영. 단순 확인/반박지표 나열에서, 각 애널로그마다
① 지금과 공통점 ② 지금과 결정적 차이점 ③ 앞으로 어느 쪽으로 전개되면
위험이 커지는지/작아지는지 ④ 어느 쪽으로 전개되면 상승 기대가
강해지는지/약해지는지 — 4개 축을 명시적으로 분리했다. **위험 축과
상승기대 축은 서로의 반대말이 아니다** — 예를 들어 거시침체 리스크가
낮아지는 것과 SK하이닉스 AI 사이클 상승 기대가 강해지는 것은 별개
질문이라, 따로 판단해야 헷갈리지 않는다. 오늘은 최초 설정이라 아직
지표 판정을 안 했음 — 다음 체크부터 매일 확인.

**🔄 2026-07-26 전면 교체**: 2026-06 데이터 반영으로 **L(유동성)이
-0.62 → +0.13으로 부호 전환**(완화적→긴축적)하면서 상위 애널로그가
전부 바뀌었다. 이전 카드(1957-04·1979-04·2002-12)는 아래 "이전 카드
보관" 항목으로 내리고, 새 상위 3개로 교체한다.

**세 애널로그의 공통 서사 — 반드시 먼저 읽을 것**: 새로 잡힌 세 시기는
모두 **"실질금리가 마이너스에서 플러스로 막 전환된 직후"**라는 공통점을
가진다(L: 1957-01 -0.145 / 1968-01 +0.963 / 2005-11 +0.545, 지금 +0.13).
그리고 **세 시기 모두 1~2년 안에 리세션이 왔다**(1957-08, 1969-12,
2007-12). 이건 불편하지만 정직하게 기록해야 하는 신호다. 다만 세 시기
어디에도 **AI CapEx 사이클 같은 별도 성장엔진은 없었다** — 이 차이가
이번에도 성립하는지가 모든 카드의 공통 분기점이다.

### ① 1957-01형 — "긴축 전환 직후, 침체 7개월 전"

**공통점**: 물가 가속이 눈에 띄게 둔화되고(I +0.0075 vs 지금 +0.0083)
고용은 오히려 악화되기 시작한(G -0.2 vs 지금 -0.1) 국면. 실질금리가
중립 부근에서 긴축 쪽으로 넘어가던 바로 그 지점이라는 게 가장 닮았다.

**차이점**: 1957년의 성장 둔화는 전후 설비투자 사이클이 자연 소진된
결과였지만, 지금은 AI 데이터센터·HBM이라는 초대형 투자 사이클이
**한창 진행 중**이다 — 거시가 식어도 반도체 수요는 별도 동력으로
버틸 여지가 그때보다 훨씬 크다.

- 🔴 **위험↑**: 신용스프레드 확대 + 산업생산·소비심리 동시 둔화 →
  1957년처럼 수개월 내 실제 침체 전이 확률↑
- 🟢 **위험↓**: 고용지표가 반등해 G가 플러스로 복귀 → 이 애널로그와
  거리 자체가 멀어짐
- 🚀 **상승기대↑**: 거시 둔화에도 하이퍼스케일러 CapEx가 유지되면
  (["경쟁생존논리"](sk-hynix-analyst-thesis-checkpoints.md#3-1-추적-프레임--경쟁-생존-논리-vs-roic-규율-2026-07-23-사용자-논의) 참고)
  → SK하이닉스 디커플링 가능
- 📉 **상승기대↓**: 침체 신호가 데이터센터 투자 둔화로 전이 → HBM 수요
  자체 훼손(최악 조합)

### ② 1968-01형 — "긴축은 시작됐는데 물가는 아직 안 잡힘" (신규)

**공통점**: 실질금리가 플러스로 전환됐고(L +0.963), 물가 가속은 둔화
중이지만 아직 목표 수준으로 내려오진 않은 어중간한 국면. **"긴축이
시작됐지만 효과가 확인되기 전"**이라는 시점이 지금과 겹친다.

**차이점**: 1968년 인플레는 베트남전 재정지출+Great Society라는 **재정발
수요 인플레**였고, 정책이 이를 방치하며 1970년대 대인플레로 번졌다.
지금은 원인이 **공급충격(유가)+AI 설비투자**로 성격이 다르고, Fed의
대응 속도·커뮤니케이션도 그때와 비교가 안 될 만큼 빠르다.

- 🔴 **위험↑**: 유가 급등이 2차 효과(임금·기대인플레)로 번지면서 Fed가
  긴축을 실제 재개 → 1968~70년형 "긴축 실패 후 대인플레" 경로
- 🟢 **위험↓**: 유가 스파이크가 지정학 이벤트로 단기 소멸하고 근원물가
  (6월 2.6%)가 계속 안정 → 인상 명분 소멸
- 🚀 **상승기대↑**: 물가 상승분이 AI 전력·설비 수요發로 확인되면
  ("나쁜 인플레"가 아니라 "성장통") → 메모리 수요 강세의 방증
- 📉 **상승기대↓**: 7월 FOMC 실제 인상 → 저PER(6.8배) 근거는 유지돼도
  시장 전체 멀티플 리레이팅이 지연

### ③ 2005-11형 — "긴축 후반, 자산가격은 아직 버티는 중" (신규)

**공통점**: 긴축 사이클 후반부에 실질금리가 플러스인데도(L +0.545)
**성장은 여전히 양호(G +0.4)**했던 국면. 지금도 미국 성장이 급격히
꺾이진 않은 상태라는 점이 닮았다.

**차이점**: 2005년 말의 버팀목은 **주택버블**이었고 2년 뒤 그게 터지며
GFC로 이어졌다. 지금의 버팀목은 AI 인프라 투자인데, **부채 레버리지가
아니라 빅테크의 영업현금흐름으로 조달**된다는 점이 결정적으로 다르다
([ROIC 프레임](roic-as-investment-criterion.md) 참고) — 다만 "그 현금흐름이
계속 나오느냐"가 곧 ROIC 규율 논쟁 그 자체다.

- 🔴 **위험↑**: AI 투자가 회사채·부채 기반으로 옮겨가는 신호(메타의
  120억달러 회사채 발행 같은 사례가 확산) → 2005년형 레버리지 취약성 재현
- 🟢 **위험↓**: 하이퍼스케일러 FCF가 CapEx를 계속 감당 → "버블이 아니라
  현금흐름 기반 투자"라는 구분이 유지됨
- 🚀 **상승기대↑**: 긴축 후반임에도 성장이 유지되면 = 연착륙 시나리오,
  고멀티플 자산 전반 리레이팅
- 📉 **상승기대↓**: 긴축 누적 효과가 시차를 두고 실물로 전이(2005→2007
  패턴) → AI CapEx도 결국 후행적으로 둔화

### 📦 이전 카드 보관 — 1979-04형 (2026-07-26 상위권 이탈, 그러나 감시 유지)

2026-05 기준으로는 2순위였던 **1979-04형(2차 오일쇼크 직전)**이 6월
데이터 반영 후 상위 5위 밖으로 밀렸다. **그런데 이건 역설적인 상황이다** —
6월 CPI는 에너지 -5.7%로 디스인플레이션을 찍었지만, **7월 말 실제로
브렌트유가 $100을 돌파**했다(7/23~25, 중동 긴장). 즉 **모델이 보는 6월과
현실의 7월이 정반대 방향**이고, 이 시차가 지금 시장 불안의 핵심이다.

**따라서 이 카드는 삭제하지 않고 감시 상태로 유지한다** — 7월 CPI가
발표되는 **8월 중순**에 유가 급등이 반영되면 1979형이 다시 상위로
복귀할 가능성이 크다. 당시 기록해둔 🔴위험↑ 트리거("에너지 급등 or
Fed 긴축 재개")는 **2026-07-25에 실제로 발동**했다(위키가 예고한 리스크가
현실화된 첫 사례로 기록).

### SK하이닉스 관점에서의 함의

세 애널로그 모두에서 공통적으로 드러나는 건, **"AI CapEx 지속 여부"가
위험 축과 상승기대 축 양쪽을 동시에 좌우하는 스윙팩터**라는 점이다.
①·③번은 "메모리 수요 자체가 거시 침체로 훼손"되는 하방 시나리오,
②번은 "물가·금리 재가속으로 밸류에이션 멀티플이 눌리는" 시나리오로
성격이 다르지만, 셋 다 실현되면 [HBM Cycle Score](hbm-cycle-score.md)의
붕괴조건과는 별개로 "매크로발 디레이팅" 리스크로 취급해야 한다.

**🔴 2026-07-26 갱신 — L 부호 전환의 실전적 의미**: 6월 데이터에서
L(유동성)이 **-0.62 → +0.13으로 부호가 바뀐 것**이 이번 국면 판정의
가장 중요한 변화다. 계산식상 L = 연방기금금리 − CPI YoY이므로, **명목금리가
그대로인데(3.63%) 물가가 내려오면(4.25%→3.5%) 실질금리가 자동으로
올라간다**. 즉 Fed가 아무 것도 안 해도 **실질 긴축 강도는 강해지고
있다**는 뜻이다.

이게 SK하이닉스에 직결되는 이유: 주가 = 이익 × 멀티플인데, **실질금리
상승은 멀티플(할인율)을 직접 누른다**. 그리고 SK하이닉스처럼 이익
성장의 상당 부분이 2027~2028년에 몰려있는 **장기 듀레이션 자산일수록
할인율 변화에 더 민감**하다. 7월 하순 미 국채 30년물이 5.19%(2007년
이후 최고 근접)까지 오른 것과 SK하이닉스가 고점 대비 -41% 빠진 것은
**"펀더멘털은 그대로인데 주가만 빠지는" 현상의 거시적 설명**이다 —
이익(분자)은 안 변했고 할인율(분모)이 변한 것. 상세는
[주가 상승의 정당성 분석](rally-justification-analysis.md)의 이격도
게이지와 함께 볼 것.

## 5. 수렴도(convergence) 스코어 — 다음 체크부터 가동

```
score = Σ(확인지표 충족 +1) − Σ(반박지표 충족 -1)
convergence_pct = (score − min) / (max − min) × 100
```

정량 지표는 가능하면 FRED/웹검색으로 직접 확인, 정성 지표(유가 재급등
여부 등)는 최근 7일 뉴스 판단 + 근거 URL 기록. 오늘은 최초 설정이라
0%(중립) 기준선만 잡아두고, 다음 체크부터 실측 시작.
