"지금 미국 거시국면이 어디에 있고, 가장 닮은 과거 스토리가 어떻게
흘러갔는지, 오늘 그 스토리에 가까워졌는지 멀어졌는지"를 매일 추적하는
프레임. 사용자가 다른 대화에서 이미 구축한 방법론(G/I/L 산식, 1954~2026
원자료, 역사적 사례 매칭)을 이 위키의 SK하이닉스 데일리 리포트에 접목한
것 — [HBM Cycle Score](hbm-cycle-score.md)가 "SK하이닉스 미시 축"이라면
이 페이지는 그 위에 얹히는 "거시 배경 축"이다.

## 0. 이 저장소의 다른 "경제계절" 시스템과의 관계 (2026-07-30 밤 발견)

이 저장소 `main` 브랜치에는 이 페이지와 **완전히 별개로 구축된** 두 개의
자동화 시스템이 이미 있다 — 다른 Claude Code 세션이 만든 것으로 보이며,
지금까지 이 위키·SK하이닉스 데일리 리포트에는 한 번도 언급되지 않았다:

1. **Investment Clock**(`src/clock/`, 매일 08:00 KST GitHub Actions) —
   미국 거시 4국면(Recovery/Overheat/Stagflation/Reflation) 모델. 결과는
   `docs/index.html`(GitHub Pages 대시보드) + `data/history.csv`에 매일
   커밋됨.
2. **PEOS**(Personal Economic Operating System, `engine/`, 매일 06:00
   KST) — 미국·한국 거시 Regime(Recovery/Early Expansion/Expansion/Late
   Expansion/Slowdown/Recession) + 반도체·투자·채권·환율·부동산·청약까지
   개인화한 풀리포트. 결과는 `report/<날짜>.md`+`docs/peos-daily.html`.

**둘 다 GitHub Actions에서는 매일 정상 실행되지만, 알림 채널
(Slack/이메일) 시크릿이 비어있어 아무에게도 전달되지 않고 있었다** —
2026-07-30 사용자 문의로 발견, 앞으로 SK하이닉스 데일리 리포트에 통합해
전달하기로 결정.

**⚠️ 오늘(2026-07-30) 세 시스템의 판정이 서로 다르다 — 억지로 통일하지
않고 병기한다**:
- 이 페이지(G/I/L, CPI 기반): **stagflation**(1957-01형 최근접)
- Investment Clock(CPI YoY 기반): **Overheat(과열)**, 유리자산 원자재
- PEOS(미국): **Slowdown**, PEOS(한국): **Early Expansion**

세 시스템이 쓰는 입력 지표·계산식·기준연도가 다르므로 같은 "경제계절"이라는
말을 써도 직접 비교는 위험하다 — **이 페이지는 계속 G/I/L·역사적
애널로그 매칭이라는 고유 역할을 유지**하고, Investment Clock·PEOS 판정은
"다른 방법론의 참고 의견"으로 매일 리포트에 나란히 병기한다(하나로
합치거나 어느 한쪽을 정답으로 취급하지 않음).

## 1. G/I/L 국면 점수

```
G(성장) = -(실업률_t − 실업률_t-12)        # 양수 = 개선
I(물가) = CPI YoY_t − CPI YoY_t-6           # 양수 = 물가 가속
L(유동성) = 연방기금금리_t − CPI YoY_t×100   # 양수 = 긴축적
```

4분면: G>0·I<0 = **recovery** / G>0·I≥0 = **overheat** / G≤0·I>0 =
**stagflation** / 그 외 = **reflation**

**역사적 유사 시기**는 1954~2026년 전체 월별 G/I/L을 z-score로
표준화한 뒤, 오늘과 유클리드 거리가 가장 가까운 과거 달들을 찾는
방식(최근 24개월은 자기상관 방지를 위해 후보에서 제외, 매칭된 시기끼리는
최소 12개월 간격 유지).

## 1-1. 거시지표 자동 수집 도구 (2026-07-24 밤 추가, 같은 날 밤 GitHub Actions로 전환)

[`scripts/macro_data.py`](../../scripts/macro_data.py) — 이 페이지의 G/I/L
계산과는 별개로, 사용자가 대화 중 "금리 지금 어때?", "GDP 어때?" 하고 물으면

**아키텍처(투자자수급 트래커와 동일 패턴)**: 처음엔 "Claude가 라이브

API 키를 별도로 넣어야 해서(GitHub Secrets는 Actions 러너에만 보임) 사용자가
"GitHub에서 다 수집해두자"로 방향을 바꿨다. 지금 구조:
[`.github/workflows/macro-data-sync.yml`](../../.github/workflows/macro-data-sync.yml)이
매일 07:10 KST에 `python3 scripts/macro_data.py sync`를 실행해 프리셋 전체를
조회하고 `sources/macro-series.csv`(series/date/value/provider/fetched_at
롱포맷)에 upsert·커밋 — **API 키는 GitHub Secrets에만 있으면 되고, Claude는
이 CSV 파일을 읽기만 하면 된다.** investor_flow.py+sk-hynix-daily-report.yml과
완전히 같은 "GitHub이 수집, Claude는 판단/조회"역할 분담.

## 2. 데이터 파이프라인 (아키텍처)

```
sources/macro-database-1954-2026.md   ← 원자료(CPI/실업률/연방기금금리, 사용자 시드데이터)
        │
        ▼
scripts/regime_engine.py              ← G/I/L 계산 + 역사적 매칭 (파이썬, 라우틴이 bash로 직접 실행)
        │
        ▼
이 페이지("체크 이력")에 매일 결과 기록
```

**신규 월 데이터 반영 경로 — 웹검색과 API 두 가지 다 지원**:
- (A) 매일 아침 체크가 `python3 scripts/regime_engine.py`를 실행해 시드
  데이터의 최신월 기준 결과를 계산. 이 최신월이 실제 이번 달보다 오래됐으면
  (CPI/실업률/연방기금금리는 월 1회만 발표되므로), 웹검색으로 신규 발표치를
  확인해 `python3 scripts/regime_engine.py --append-month YYYY-MM --cpi X --unrate Y --fedfunds Z`로
  원자료에 새 행을 추가한 뒤 재계산.
- (B) 사용자가 **이미 다른 Claude Code 세션에서 FRED API 연동 파이프라인을
  운영 중** — 그쪽에서 더 정확한/실시간 수치가 나오면, 그 값을 그대로
  같은 `--append-month` 커맨드에 넣거나 sources/macro-database-1954-2026.md의
  CSV 블록에 직접 append하면 된다. 스크립트 입장에서는 값이 웹검색에서
  왔는지 API에서 왔는지 구분하지 않음 — **어느 경로로 넣어도 동일하게
  작동하도록 설계**. 값을 넣을 때 log.md에 출처(웹검색 vs API)를 남길 것.

## 4. 스토리 프로필 & 관전 포인트 (상위 3개 애널로그)

**2026-07-24 갱신 — 공통점/차이점 + 양방향 시나리오 구조로 고도화**:
사용자 피드백 반영. 단순 확인/반박지표 나열에서, 각 애널로그마다
① 지금과 공통점 ② 지금과 결정적 차이점 ③ 앞으로 어느 쪽으로 전개되면
위험이 커지는지/작아지는지 ④ 어느 쪽으로 전개되면 상승 기대가
강해지는지/약해지는지 — 4개 축을 명시적으로 분리했다. **위험 축과
상승기대 축은 서로의 반대말이 아니다** — 예를 들어 거시침체 리스크가
낮아지는 것과 SK하이닉스 AI 사이클 상승 기대가 강해지는 것은 별개
질문이라, 따로 판단해야 헷갈리지 않는다. 오늘은 최초 설정이라 아직
지표 판정을 안 했음 — 다음 체크부터 매일 확인.

**🔄 2026-07-26 전면 교체**: 2026-06 데이터 반영으로 **L(유동성)이
-0.62 → +0.13으로 부호 전환**(완화적→긴축적)하면서 상위 애널로그가
전부 바뀌었다. 이전 카드(1957-04·1979-04·2002-12)는 아래 "이전 카드
보관" 항목으로 내리고, 새 상위 3개로 교체한다.

**세 애널로그의 공통 서사 — 반드시 먼저 읽을 것**: 새로 잡힌 세 시기는
모두 **"실질금리가 0선 근처에 있고, 물가 가속이 둔화되는 중이며, 성장은
아직 무너지지 않은"** 국면이다. 다만 **L 값 자체는 셋이 꽤 다르다**
(1957-01 **-0.145** / 1968-01 +0.963 / 2005-11 +0.545, 지금 +0.13) —
"셋 다 실질금리 플러스 전환 직후"라고 묶는 건 사실과 다르므로(1957-01은
여전히 마이너스) 그렇게 쓰지 말 것. 매칭은 L 단독이 아니라 G·I·L
**3차원 거리**로 이뤄진다.

그리고 **세 시기 모두 1~2년 안에 리세션이 왔다**(1957-08, 1969-12,
2007-12). 이건 불편하지만 정직하게 기록해야 하는 신호다. 다만 세 시기
어디에도 **AI CapEx 사이클 같은 별도 성장엔진은 없었다** — 이 차이가
이번에도 성립하는지가 모든 카드의 공통 분기점이다. 또한 세 시기는 모두
**지금보다 실질금리가 높거나 비슷했다**는 점도 같이 봐야 한다 — 즉
"긴축 강도"로 보면 지금이 셋 중 가장 약하다.

### ① 1957-01형 — "긴축 전환 직후, 침체 7개월 전"

**공통점**: 물가 가속이 눈에 띄게 둔화되고(I +0.0075 vs 지금 +0.0083)
고용은 오히려 악화되기 시작한(G -0.2 vs 지금 -0.1) 국면. 실질금리가
0선 바로 아래(L -0.145, 지금 +0.13)에서 완만히 올라오던 지점이라는 것도
닮았다 — 다만 **당시도 지금도 "긴축 구간"은 아니었다**(중립 미만).

**차이점**: 1957년의 성장 둔화는 전후 설비투자 사이클이 자연 소진된
결과였지만, 지금은 AI 데이터센터·HBM이라는 초대형 투자 사이클이
**한창 진행 중**이다 — 거시가 식어도 반도체 수요는 별도 동력으로
버틸 여지가 그때보다 훨씬 크다.

- 🔴 **위험↑**: 신용스프레드 확대 + 산업생산·소비심리 동시 둔화 →
  1957년처럼 수개월 내 실제 침체 전이 확률↑
- 🟢 **위험↓**: 고용지표가 반등해 G가 플러스로 복귀 → 이 애널로그와
  거리 자체가 멀어짐
- 🚀 **상승기대↑**: 거시 둔화에도 하이퍼스케일러 CapEx가 유지되면
  (["경쟁생존논리"](sk-hynix-analyst-thesis-checkpoints.md#3-1-추적-프레임--경쟁-생존-논리-vs-roic-규율-2026-07-23-사용자-논의) 참고)
  → SK하이닉스 디커플링 가능
- 📉 **상승기대↓**: 침체 신호가 데이터센터 투자 둔화로 전이 → HBM 수요
  자체 훼손(최악 조합)

### ② 1968-01형 — "긴축은 시작됐는데 물가는 아직 안 잡힘" (신규)

**공통점**: 실질금리가 플러스로 전환됐고(L +0.963), 물가 가속은 둔화
중이지만 아직 목표 수준으로 내려오진 않은 어중간한 국면. **"긴축이
시작됐지만 효과가 확인되기 전"**이라는 시점이 지금과 겹친다.

**차이점**: 1968년 인플레는 베트남전 재정지출+Great Society라는 **재정발
수요 인플레**였고, 정책이 이를 방치하며 1970년대 대인플레로 번졌다.
지금은 원인이 **공급충격(유가)+AI 설비투자**로 성격이 다르고, Fed의
대응 속도·커뮤니케이션도 그때와 비교가 안 될 만큼 빠르다.

**⚠️ [OPINION, 김광석 교수 전망(2026-07-30 INGEST)] 재정발 유동성 채널
재부각 가능성**: 중간선거를 앞두고 통화정책이 아니라 **재정정책에 의한
유동성 공급**이 시장을 움직일 핵심 변수가 될 것이라는 외부 전문가 시각이
제기됐다 — 만약 실현되면 1968년의 "재정발 수요 인플레" 메커니즘과 방향은
다르지만(그때는 인플레 압력, 지금 시나리오는 유동성 공급 자체가 목적) **정부
재정지출이 국면을 좌우한다는 구조적 유사성**은 있다. 아직 검증된 사실이
아니라 예측이므로 L(유동성) 산식 자체에 반영하지 않고, 실제 재정지출
집행 데이터가 나오면 그때 재평가([트럼프 중간선거 트래커](trump-midterm-tracker.md)
경제 카테고리와 교차연동).

- 🔴 **위험↑**: 유가 급등이 2차 효과(임금·기대인플레)로 번지면서 Fed가
  긴축을 실제 재개 → 1968~70년형 "긴축 실패 후 대인플레" 경로
- 🟢 **위험↓**: 유가 스파이크가 지정학 이벤트로 단기 소멸하고 근원물가
  (6월 2.6%)가 계속 안정 → 인상 명분 소멸
- 🚀 **상승기대↑**: 물가 상승분이 AI 전력·설비 수요發로 확인되면
  ("나쁜 인플레"가 아니라 "성장통") → 메모리 수요 강세의 방증
- 📉 **상승기대↓**: 7월 FOMC 실제 인상 → 저PER(6.8배) 근거는 유지돼도
  시장 전체 멀티플 리레이팅이 지연

### ③ 2005-11형 — "긴축 후반, 자산가격은 아직 버티는 중" (신규)

**공통점**: 긴축 사이클 후반부에 실질금리가 플러스인데도(L +0.545)
**성장은 여전히 양호(G +0.4)**했던 국면. 지금도 미국 성장이 급격히
꺾이진 않은 상태라는 점이 닮았다.

**차이점**: 2005년 말의 버팀목은 **주택버블**이었고 2년 뒤 그게 터지며
GFC로 이어졌다. 지금의 버팀목은 AI 인프라 투자인데, **부채 레버리지가
아니라 빅테크의 영업현금흐름으로 조달**된다는 점이 결정적으로 다르다
([ROIC 프레임](roic-as-investment-criterion.md) 참고) — 다만 "그 현금흐름이
계속 나오느냐"가 곧 ROIC 규율 논쟁 그 자체다.

- 🔴 **위험↑**: AI 투자가 회사채·부채 기반으로 옮겨가는 신호(메타의
  120억달러 회사채 발행 같은 사례가 확산) → 2005년형 레버리지 취약성 재현
- 🟢 **위험↓**: 하이퍼스케일러 FCF가 CapEx를 계속 감당 → "버블이 아니라
  현금흐름 기반 투자"라는 구분이 유지됨
- 🚀 **상승기대↑**: 긴축 후반임에도 성장이 유지되면 = 연착륙 시나리오,
  고멀티플 자산 전반 리레이팅
- 📉 **상승기대↓**: 긴축 누적 효과가 시차를 두고 실물로 전이(2005→2007
  패턴) → AI CapEx도 결국 후행적으로 둔화

### 📦 이전 카드 보관 — 1979-04형 (2026-07-26 상위권 이탈, 그러나 감시 유지)

2026-05 기준으로는 2순위였던 **1979-04형(2차 오일쇼크 직전)**이 6월
데이터 반영 후 상위 5위 밖으로 밀렸다. 6월 CPI는 에너지 -5.7%(MoM)로
디스인플레이션을 찍었는데, 7월 하순 브렌트유가 $100선을 터치했기 때문에
처음엔 "모델의 6월과 현실의 7월이 정반대"라고 기록했다.

**⚠️ 2026-07-26 09시대 정정 — "7월 유가 급등"은 레벨이 아니라 속도였다**
(사용자가 브렌트 3개월 차트 제시). 두 가지를 바로잡는다:

1. **레벨 기준으로는 오히려 내려온 상태다.** 7/25 종가 **$98.70**
   (당일 고가 $98.88). 그런데 **4월은 $100~111, 5월 고점은 약 $115**로
   지금보다 훨씬 높았다. "유가 급등으로 인플레 재점화"라는 서술은
   **3주간의 변화율(+38%, $71→$98.7)을 레벨 서사로 바꿔 쓴 것**이다.
   시장의 인상확률 리프라이싱(12%→38%)이 반응한 건 이 **속도**이지
   절대 레벨이 아니다. 참고로 내가 인용해온 "$100.39"는 7/24 장중
   터치값으로, 현재가로 쓰면 과장이다.
2. **🔑 그래서 7월 CPI에는 이 스파이크가 거의 안 잡힐 가능성이 크다.**
   CPI 에너지는 **월평균** 기준인데, 7월은 **$71 바닥에서 시작**해서
   하순에야 올랐다. 일별 경로를 개략 가중하면 7월 평균은 **약 $85**로,
   EIA 기준 **6월 평균 $85와 사실상 같다**(6월은 5월 $107에서 -$22
   급락한 달). 즉 **7월 에너지는 MoM 대략 보합**이지 재점화가 아니다.
   게다가 휘발유 소매가는 원유에 2~4주 후행하므로 스파이크는 더 밀린다.
   → **유가 급등이 물가지표에 실제로 잡히는 건 8월 CPI(9월 중순 발표)**
   이고, 그것도 **$98~100선이 8월 내내 유지될 때만** 그렇다.

**따라서 캘린더를 수정한다**: 8월 중순 발표되는 7월 CPI는 이 카드의
분기점이 **아니다** — 오히려 또 한 번 온건하게 나올 공산이 크고, 그렇다면
시장에는 **안도 재료**가 된다. 1979형 복귀 여부의 진짜 분기점은
**9월 중순 발표되는 8월 CPI**이며, 그 전에 볼 선행 조건은 "브렌트가
8월에도 $95+ 유지되는가"다. 이 카드는 그 조건부로 감시를 유지한다.

**⚠️ 정밀도 한계**: 7월 평균 $85는 차트 이미지에서 일별 경로를 눈으로
읽어 가중한 추정치(±$3 수준)이고, 6월 $85는 웹검색으로 인용한 EIA
수치다 — 둘 다 API 수집 원자료가 아니다. 이 오류가 재발하지 않도록
[`scripts/macro_data.py`](../../scripts/macro_data.py)에 브렌트/WTI
일별 시리즈(FRED `DCOILBRENTEU`/`DCOILWTICO`)를 프리셋으로 추가했다 —
다음 수집분부터는 월평균을 직접 계산해서 쓸 것.

당시 기록해둔 🔴위험↑ 트리거는 "에너지 급등 **or** Fed 긴축 재개"였는데,
**"급등"의 판정 기준을 스팟 변화율이 아니라 "월평균이 전월 대비 상승"으로
바꿔 적용하면 7/25 시점에는 아직 미발동**이다. 처음에 "발동했다"고 기록한
것을 이렇게 정정한다(위키가 스스로 예고한 트리거의 판정 기준이 모호했던
사례로 남긴다).

### SK하이닉스 관점에서의 함의

세 애널로그 모두에서 공통적으로 드러나는 건, **"AI CapEx 지속 여부"가
위험 축과 상승기대 축 양쪽을 동시에 좌우하는 스윙팩터**라는 점이다.
①·③번은 "메모리 수요 자체가 거시 침체로 훼손"되는 하방 시나리오,
②번은 "물가·금리 재가속으로 밸류에이션 멀티플이 눌리는" 시나리오로
성격이 다르지만, 셋 다 실현되면 [HBM Cycle Score](hbm-cycle-score.md)의
붕괴조건과는 별개로 "매크로발 디레이팅" 리스크로 취급해야 한다.

**2026-07-26 갱신 — L 부호 전환을 어떻게 읽어야 하나 (⚠️ 같은 날 오전 정정)**:
6월 데이터에서 L(유동성)이 **-0.62 → +0.13으로 부호가 바뀐 것**이 이번
애널로그 교체의 직접 원인이다. 계산식상 L = 연방기금금리 − CPI YoY이므로,
명목금리가 3.63%로 그대로인 채 물가가 4.25%→3.5%로 내려오면 L은 산술적으로
올라간다.

**⚠️ 정정 — 처음에 이걸 "Fed가 아무 것도 안 해도 실질 긴축이 강해지고
있다"고 썼는데, 이는 과도 해석이다**(사용자 지적, 2026-07-26 08시대).
세 가지가 틀렸다:

1. **0을 넘은 것과 중립금리를 넘은 것은 다르다.** 실질중립금리(r\*)는
   대체로 +0.5~1.0%로 추정되는데 지금은 +0.13%다. 즉 "완화적 → 덜
   완화적"으로 **정상화**된 것이지 긴축 구간에 들어간 게 아니다. 애널로그
   세 시기의 L 자체가 훨씬 높다(1968-01 +0.963, 2005-11 +0.545) — 같은
   군집에 잡혔다고 해서 긴축 강도까지 같다는 뜻이 아니다.
2. **헤드라인 vs 근원.** L은 헤드라인 CPI를 쓰는데, 6월 헤드라인 하락의
   주범은 **에너지 -5.7%**였다. 근원(2.6%) 기준 실질금리는 이미 +1.0%
   부근으로 **한참 전부터 플러스**였다 — 6월에 뭔가 새로 "전환"된 게
   아니라, 변동성 큰 에너지 항목 때문에 지표가 0선을 넘어간 것에 가깝다.
   실제로 7월 유가가 $100을 넘었으므로 **L은 다음 달에 다시 마이너스로
   되돌아갈 수 있다**. 한 달짜리 부호 전환 위에 서사를 세우면 안 된다.
3. **Fed 반응함수를 뺐다.** 사용자 지적대로 **물가가 내려가면 인상 압력이
   줄어든다** — 그게 1차 효과이고 방향은 완화적이다. 교과서적으로도
   "물가 하락으로 실질금리가 산술적으로 올라가면 Fed가 명목금리를 낮춰
   실질 스탠스를 유지"한다. "Fed가 손도 안 댔는데"라는 표현은 Fed를
   수동적 존재로 가정한 건데, 그건 사실이 아니다.

**그럼 왜 실제로 할인율이 올라갔나 — 진짜 채널은 따로 있다.** 7월 하순
미 국채 30년물이 5.19%(2007년 이후 최고 근접), 10년물 4.7%까지 오르고
**7월 FOMC 인상확률이 12% → 38%로 급등**한 건 6월 디스인플레이션 때문이
아니라 **7월 유가의 급반등이 만든 인상 기대** 때문이다. 즉 시장을
움직인 건 L의 부호가 아니라 **명목 장기금리와 정책 기대의 실제 상승**이다.

**단 그 "유가 급등"도 레벨이 아니라 속도다**(2026-07-26 09시대 정정):
브렌트 7/25 종가 **$98.70**은 4월($100~111)·5월 고점(약 $115)보다 오히려
낮다. 3주 만에 $71→$98.7로 **+38% 올라온 속도**가 리프라이싱을 유발한
것이지, 절대 레벨이 인플레 위협 수준으로 간 게 아니다. 그리고 **CPI는
월평균 기준이라 7월 평균(약 $85)은 6월(약 $85)과 사실상 같다** — 7월
CPI에 이 스파이크는 거의 안 잡힌다. 상세는 아래 1979-04형 카드 참고.

정리하면 이번 국면의 긴장은 **"모델의 6월 vs 시장의 7월 스팟"**이고,
**물가지표로 확인되는 시점은 8월 CPI(9월 중순)**다.

**L 지표의 올바른 용도**: L은 **역사적 애널로그를 찾기 위한 국면 분류
입력값**이지, Fed의 정책 스탠스를 재는 계기판이 아니다. L의 변화는
"어느 과거 시기와 닮았는지"를 바꿀 뿐, 그 자체로 "긴축이다/완화다"를
선언하지 않는다. 앞으로 L을 인용할 때 이 구분을 지킬 것.

**SK하이닉스에 직결되는 부분(이건 유효)**: 주가 = 이익 × 멀티플인데
**명목 장기금리 상승은 멀티플(할인율)을 직접 누른다**. SK하이닉스처럼
이익 성장의 상당 부분이 2027~2028년에 몰려있는 **장기 듀레이션 자산일수록
할인율 변화에 더 민감**하다. 30년물 5.19%와 SK하이닉스 고점 대비 -41%가
겹치는 건 **"펀더멘털은 그대로인데 주가만 빠지는" 현상의 거시적 설명**이다 —
이익(분자)은 안 변했고 할인율(분모)이 변한 것. 상세는
[주가 상승의 정당성 분석](rally-justification-analysis.md)의 이격도
게이지와 함께 볼 것.

## 5. 수렴도(convergence) 스코어 — 다음 체크부터 가동

```
score = Σ(확인지표 충족 +1) − Σ(반박지표 충족 -1)
convergence_pct = (score − min) / (max − min) × 100
```

정량 지표는 가능하면 FRED/웹검색으로 직접 확인, 정성 지표(유가 재급등
여부 등)는 최근 7일 뉴스 판단 + 근거 URL 기록. 오늘은 최초 설정이라
0%(중립) 기준선만 잡아두고, 다음 체크부터 실측 시작.
