# Real Estate Market Entry Framework

## Framework Overview

This page defines the decision framework for real estate market entry timing, specifically:
1. **전세 전환 시점**: When to transition from 월세 to 전세 arrangement
2. **매매 진입 타이밍**: When to enter purchase market
3. **플랫폼시티 추적**: Monitoring 플랫폼시티 공공/일반분양 opportunities

The framework bridges macro economic cycles, interest rate environment, 전세가 market trends, and personal constraints to generate WAIT/ENTER signals with event-based triggers.

## Decision Hierarchy

### Layer 1: Interest Rate Environment (Primary Driver)
- **극도 완화 (≥80점)**: ENTER mode open, transaction costs reduced, 전세금 상승 기대
- **완화 (70~79)**: ENTER signal active, 전세 전환 최적 window
- **중립 (55~69)**: WAIT (marginal), monitor for clearer signals
- **긴축 (40~54)**: WAIT mandatory, financial headwinds
- **극도 긴축 (<40)**: WAIT + caution, 금융경색 우려

### Layer 2: Macro Regime (Confirmation Layer)
- **상승 (Bullish)**: Supports ENTER if rates favorable
- **조정 (Adjustment)**: Neutral, rate-dependent
- **약세 (Bearish)**: Discourages ENTER, uncertain employment outlook
- **위기 (Crisis)**: Strong WAIT signal, job security paramount

### Layer 3: 전세가 Trend (Opportunity Layer)
- **상승 (Rising)**: Urgency to enter quickly, expected to accelerate
- **보합 (Flat)**: Neutral, time-flexible
- **하강 (Falling)**: Advantage to wait, expected to stabilize lower

### Layer 4: Event Triggers (Conditional Actions)
- **기준금리 인하 발표**: 25bp+ move → recalculate from macro perspective
- **플랫폼시티 청약공시**: Top priority, immediate analysis + application if feasible
- **강남/서초 전세가 +5%**: Acceleration signal, compress decision timeline
- **Platform City 사업 진행률 > 80%**: Phase 2/3 supply incoming → wait for 일반분양

## Decision Tree

```
START: Interest Rate Check
├─ 점수 < 40 (극도 긴축)
│  └─ WAIT (80% confidence) + 금융경색 경보
├─ 점수 40-54 (긴축)
│  ├─ 거시 약세 → WAIT (80%)
│  ├─ 거시 상승/조정 → WAIT (60%)
│  └─ 전세가 하강 → WAIT + 유리 (70%)
├─ 점수 55-69 (중립)
│  ├─ 거시 상승 → WAIT (60%) [기회발생 대기]
│  ├─ 거시 약세 → WAIT (70%)
│  └─ 전세가 상승 → WAIT 우선 (65%) [타이밍 재검토]
├─ 점수 70-79 (완화)
│  ├─ 거시 상승 + Conf ≥ 75% → ENTER (75%)
│  ├─ 거시 조정 + Conf ≥ 70% → ENTER (65%)
│  ├─ 거시 약세 → WAIT (55%) [신중하게]
│  └─ 전세가 상승 → ENTER 긴급 (80%)
└─ 점수 ≥ 80 (극도 완화)
   ├─ 거시 상승 + Conf ≥ 75% → ENTER (85%) [적극]
   ├─ 거시 조정 → ENTER (75%) [주의 깊게]
   └─ 거시 약세 → WAIT (60%) [신중]

OUTPUT: Signal + Event Triggers + Next Check
```

## Event-Based Triggers (Not Price-Based)

Unlike stock trading, real estate decisions are event-driven. These events are discrete, not continuous.

| Event | Condition | Action | Urgency | Window |
|-------|-----------|--------|---------|--------|
| **기준금리 25bp 인하** | 금리 결정 발표 + 연속 완화 신호 | 전세 전환 timing 앞당기기 | 높음 | 2-3개월 내 |
| **플랫폼시티 청약공시** | 공개 공시 (공공분양) | 즉시 당첨확률 분석 + 청약 | 최고 | 당일 신청 |
| **강남/서초 전세가 +5%** | 1개월 연속 상승 또는 급등 | 긴급 진입 검토, 전세 대기자 순서 가속화 | 높음 | 1-2주 내 |
| **외국인 순매수 +5조↑** | 1개월 순매수 누적 | 부동산 경기 회복신호, ENTER 신뢰도 ↑ | 중간 | 1-3개월 |
| **기준금리 추가 인상** | 25bp+ 인상 방향 전환 | WAIT 신호 강화, 급한 결정 지연 | 높음 | 재평가 필수 |

## Macro-Real Estate Linkage Patterns

### Interest Rate ↓ → 전세금 ↑
- Signal: 기준금리 인하, 완화 사이클 시작
- Impact: 금융 유동성 ↑ → 전세 수요 증가 → 전세금 상승 가속
- Timing: 1-3개월
- **Action**: 전세 전환 기한을 앞당기고, 강남/강북 구분 없이 기회 포착

### Macro 상승 → 고용 안정 → Housing Demand ↑
- Signal: 거시 신뢰도 상승, 실업률 안정, 기업 실적 개선
- Impact: Job security ↑ → 장기거주 결정 → 전세/매매 진입
- Timing: 2-3개월
- **Action**: ENTER 신호 약해지지 않는 한 진입 시점 단축

### Foreign Investor Inflow ← Macro Recovery
- Signal: 외국인 순매수 누적, 국제 펀드 한국 부동산 관심
- Impact: 부동산 수요 확대 → 전세가 상승 → 경쟁 심화
- Timing: 1-2개월
- **Action**: 기회의 창이 닫힐 수 있음, 대기보다 진입 우선

## Risk Management Rules

### Personal Housing Constraints
- Current situation: 월세 거주 (타건물, 기간 2027년 4월 만료)
- Maximum urgency level: 중간 (교육/생활 안정성 고려)
- Portfolio constraint: 전세자금 확보 가능 범위 내 결정

### Decision Timelines
- WAIT 신호 지속: 최대 6개월 (자동 재평가)
- ENTER 신호 인식 → 실행까지: 2-4주 권장 (시장 변동성 고려)
- 플랫폼시티 청약공시 → 청약 신청: 당일 또는 다음날

### Event-Driven Recalculation
- 기준금리 발표 후: 24시간 내 신호 재평가
- 플랫폼시티 공시: 즉시 영향 분석
- 전세가 급등 (+5%+): 48시간 내 긴급 검토

## Framework Maintenance

### Triggers for Framework Revision
- [ ] Interest rate environment crosses major threshold (e.g., 70 ↔ 55)
- [ ] Macro regime changes for 2+ consecutive weeks
- [ ] 전세가 momentum reverses (up → down or vice versa)
- [ ] Personal housing constraint changes (e.g., 월세 이사, 자금 추가 확보)
- [ ] Platform City project phase change or supply announcement
