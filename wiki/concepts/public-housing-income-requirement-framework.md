# 공공분양 소득요건 판별 프레임워크

## 왜 이 페이지가 필요한가

공공분양(국민주택) 모집공고를 볼 때마다 "이번엔 소득요건이 있나?"를
매번 원문 전체를 다시 읽어 판단하면 비효율적이고, 실수로 소득요건
유무를 놓치면(특히 자산가/고소득 무주택자인 이 위키 질문자 입장에서는)
"청약 가능한 줄 알았는데 사실 소득 초과로 부적격"이 되는 리스크가 있다.

2026-09-01, 3개 실제 입주자모집공고(성남복정2 A1블록, 인천계양 A6블록,
양주회천 A-26블록) 원문을 직접 대조 분석해 **소득요건이 "매번 다르게
보이는" 이유가 무작위가 아니라 사업유형(상품 브랜드) + 기준연도 통계
갱신, 단 두 변수의 조합**이라는 패턴을 확인했다. 이 페이지는 그 판별
규칙을 고정하고, 앞으로 새 공고를 넣을 때마다 이 규칙과 다른 예외가
나오면 즉시 갱신하기 위한 기준점(concept)이다.

| 공고 | 사업유형 | 평형 | 공고일 |
|------|---------|------|--------|
| 성남복정2 A1블록 | 신혼희망타운(공공분양) | 55㎡, 56㎡ | 2026.08.10 |
| 인천계양 A6블록 | 일반 공공분양(국민주택, LH) | 59/69/74/77/84㎡ | 2026.08.31 |
| 양주회천 A-26블록 | 일반 공공분양(국민주택, LH) | 59/74/84㎡ | 2026.08.27 |

## 핵심 판별 규칙

**"4. 소득기준" 챕터의 "적용대상" 첫 줄만 보면 즉시 판별 가능**:

```
"본청약(신혼부부·예비신혼부부·한부모가족) 신청자" 만 있으면
  → 신혼희망타운형: 평형 무관 전원 소득검증

"...및 전용면적 60㎡ 이하 일반공급 신청자" 가 있으면
  → 국민주택형: 특별공급은 전원 검증 + 일반공급은 60㎡ 이하만 검증
    (60㎡ 초과 일반공급은 소득 무관 — 자산가/맞벌이 고소득자도
    진입 가능한 유일한 문)
```

### 축 1 — 사업유형(상품 브랜드)이 소득검증 범위를 결정

```
신혼희망타운          → 전용면적 무관 100% 소득검증
  (사업 자체가 신혼부부 전용 특화상품이라 "일반공급" 개념 자체가 없음)

일반 공공분양(국민주택) → 특별공급 100% 검증 + 일반공급은 "60㎡ 이하만" 검증
```

이번 3건에는 없었지만 **뉴홈(나눔형/선택형)** 브랜드는 또 다른 소득검증
범위 규칙을 가질 가능성이 있음 — 다음에 뉴홈 공고가 들어오면 반드시
별도 검증 후 이 표에 행 추가할 것.

### 축 2 — 같은 국민주택형 안에서는 배율(%)이 「공공주택 특별법
시행규칙」별표6의3 전국 공통 표준을 따름

인천계양 A6 · 양주회천 A-26 두 공고의 소득기준 배율은 **완전히 동일**했다:

| 공급유형 | 배율 |
|---------|------|
| 일반 60㎡ 우선공급(1순위자) | 도시근로자 월평균소득 100~140% |
| 다자녀 우선공급 | 120~130% |
| 신혼부부 배점 | 80~100% |
| 신혼부부 일반공급 | 130~140% |
| 신생아 일반공급 | 140~150% |
| 생애최초 우선/일반 | 100~140% |
| 추첨공급(전 유형 공통) | 100~200% |

→ 우연이 아니라 법령(별표6의3)이 못박은 값이라, **같은 사업유형끼리는
배율 재확인이 불필요**하다. 절대금액(원)만 기준연도 통계로 매년 갱신됨.

### 축 3 — "매번 달라 보이는" 진짜 원인 정리

| 변동 요인 | 설명 |
|----------|------|
| 기준연도 통계 개정 | "전년도 도시근로자 가구당 월평균소득" 절대금액(원)이 매년 갱신. 이번 3건은 모두 2026년 공고라 원단위 동일(3인 이하 100% = 7,533,763원 등). 연도가 다른 공고와 비교할 땐 반드시 재확인 |
| 사업유형(상품 브랜드) | 신혼희망타운 / 국민주택(LH) / 뉴홈 나눔형·선택형 등 상품별로 소득검증 범위(몇 ㎡까지)가 원천적으로 다름 |
| 공급비율 구성 | 우선공급 90:10 vs 70:20:10 등 지구마다 비율이 다르면 실제 적용받는 배율 구간이 달라짐 (배율표 자체는 동일해도 어느 구간에 속하는지는 달라질 수 있음) |
| 출산가구 소득완화(+10~20%p) | 적용 여부·완화폭은 공고마다 명시. 이번 3건은 전부 동일 적용(2023.3.28 이후 출생 1명 +10%p, 2명 이상 +20%p) |

## 앞으로 새 공고를 입력할 때 (운영 규칙)

새 모집공고 PDF를 검토할 때마다 아래 순서로 판별하고, **이 페이지의
규칙과 다른 예외가 하나라도 발견되면 반드시 "예외 사례" 절에 append로
기록**할 것 (Concept Lifecycle Maturity 규칙에 따라 예외가 반복·확인되면
이 프레임워크 자체를 개정 검토).

```
1. 사업유형부터 확인
   → 신혼희망타운/뉴홈 나눔형/뉴홈 선택형/기타 특화상품인가?
   → 일반 국민주택(LH)인가?
2. "4. 소득기준" 챕터의 "적용대상" 첫 줄 확인
3. 배율표(<표4> 등)를 축 2의 표와 대조
   → 숫자가 다르면: (a) 기준연도가 다른지, (b) 배율 자체가 다른지 구분
4. 출산가구 완화 적용 여부·폭 확인
5. 위 1~4 중 하나라도 이 페이지 규칙과 다르면 → 아래 "예외 사례"에 기록
```

## 자동화 (2026-09-01)

위 판별 규칙은 `collectors/subscription_monitor/income_analysis.py`로
코드화됐다. NEW_MATCH(플랫폼시티/광교/원천동 키워드 매칭 신규 매물)가
잡히면 청약Home 상세페이지(PBLANC_URL)에서 모집공고문 PDF를 자동으로
찾아 다운로드 → `pdftotext`로 텍스트 추출 → 이 페이지의 두 축(사업유형,
표준 배율표)에 따라 분류 → 알림 이메일 본문에 사업유형/소득검증범위/
소득배율/예외여부를 자동 첨부한다. 코드가 판별한 `exceptions`가 비어
있지 않으면 알림에 "⚠️ 예외 발견"으로 표시되므로, **그 이메일을 받으면
원문을 직접 확인하고 아래 "예외 사례" 절에 사람이 기록**할 것 — 자동
판정 자체가 이 표에 자동으로 append되지는 않는다(오탐 가능성이 있어
사람 확인을 거치게 설계).

전 범위(모든 국민주택 일반공급)가 아니라 **키워드 매칭 신규 매물에만**
적용된다 — 5~30분마다 전국 수백 건에 PDF 파싱을 돌리는 건 과도하고
관심사(플랫폼시티/광교신도시)와도 무관하기 때문. 관련 코드:
`collectors/subscription_monitor/compose.py`(NEW_MATCH 분기),
`tests/test_subscription_income_analysis.py`(6개 케이스, 실제 3개 PDF
텍스트로 검증).

**✅ 의정부우정 A2블록(경기) — 확정: 프레임워크 규칙과 일치, "60㎡ 이하" 생략은 단순 표기 차이**

2026-09-01, 사용자 질문("그래서 소득요건이 필요한거야 아니야?")을 계기로
원문 전체(소득기준 챕터 8000자 + 공급대상 문구)를 직접 열어 확정했다.
결정적 문구:

> "공급대상 : 공공분양주택 463세대 (**전용면적 59㎡ 463세대**)"

**이 단지는 애초에 전용면적 59㎡ 단일 타입만 공급 — 60㎡ 초과 세대가
존재하지 않는다.** 소득기준 표 자체는 "일반 60㎡ 이하 우선공급(1순위자,
30%) + 신생아 우선공급(50%) + 추첨공급(20%)" 구조로 기존 3건과 배율
(100%/140%/200%)까지 완전히 동일 — 문서 작성자가 "적용대상" 한 줄
요약에서만 "일반공급"이라 축약하고 "전용면적 60㎡ 이하"를 생략했을 뿐,
어차피 전 세대가 60㎡ 이하라 그 구분이 무의미했기 때문. **판정: (b) 단순
표기 차이 — 프레임워크 규칙 위반 아님.**

→ **다음에 이 패턴("적용대상" 줄에 "60㎡ 이하" 없이 "일반공급"만 있는
경우)을 다시 만나면, 먼저 "공급대상" 문구에서 이 단지의 전체 평형
구성을 확인할 것 — 전 세대가 60㎡ 이하라면 이번처럼 단순 표기 생략,
60㎡ 초과 세대가 섞여 있는데도 "60㎡ 이하" 생략이면 그때 비로소 진짜
축1 위반 예외.** 공고문: https://apply.lh.or.kr/lhapply/apply/wt/wrtanc/selectWrtancInfo.do?panId=0000061159

**❌ 남양주진접2지구 A-4블록(경기) — 파싱 실패, 원인 미확정**

`analyze_listing()`이 "'4. 소득기준' 챕터를 찾지 못함"으로 실패. 이 공고명이
다른 3건과 다른 점: "···**잔여세대 추가입주자모집공고**"(본청약이 아니라
잔여세대만 추가로 모집하는 별도 유형) — 이런 공고는 챕터 번호 체계나 목차
구조가 표준 3건과 다를 가능성이 있음. PDF 다운로드 자체는 성공했으나 텍스트
파싱에서 막힘. **원문을 직접 열어 실제 목차 구조를 확인 후, 필요시
`INCOME_SECTION_HEADERS`(현재 "4. 소득기준"/"4. 소득 판정 기준"만 등록)에
새 헤더 패턴을 추가할 것.**

LH가 아니거나(지방공사·민간참여 공공분양 등), LH청약플러스 등록명이

`income_analysis.py`에 해당 시행사(iH 인천도시공사, 울산도시공사 등) 지원을
추가할 것.**

이 위키 질문자(무주택, 소득제한 없는 유형 우선 선호 — [사용자
프로필](../entities/user-profile.md) 참고)에게는 **"60㎡ 초과 + 일반공급"
조합이 소득 무관 진입 가능한 유일한 합법 루트**다. 신혼희망타운형
공고(전 평형 소득검증)는 애초에 이 전략과 맞지 않으므로, 신규 공고를
분류할 때 사업유형만 보고도 "검토 대상인지"를 1차 필터링할 수 있다.
